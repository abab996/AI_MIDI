## P2 · 乐器箱（原输出机架）+ 编排 v2 + ops API + 音源选择器 + AI 编曲工具

- 输出机架升级为**乐器箱**：轨道音源只能来自机架（不变量在前后端三处强制）；
  机架条目 id 用 `rk_` + FNV-1a-64 前 12 位（Go 与前端同构，已有向量测试）。
- 编排模型升到 **v2**：`{version:2, rev, bpm, snap, ppb, loop, tracks[], rack, pianoRoll, mixer}`。
- **共用 ops API**：`POST /api/projects/{id}/arrangement/ops`（`addTrack/removeTrack/renameTrack/`
  `setTrackSource/setTrackMix/addRackItem/setRackItem/removeRackItem/setPianoRoll/setBpm/setLoop/setFxSlot/setMaster`），
  界面与 AI 走同一条路径；结构化"AI 改动回显"只带 `rev/changed/summary`，前端按类别**外科式**应用，
  绝不覆盖未保存的本地片段编辑。
- **音源选择器**：分类/搜索/键盘（↑↓/Enter/Esc/Tab）、两级预设视图、分配后立即落库。
- **AI 编曲工具**：`list_sound_sources / list_rack / add_rack_item / remove_rack_item / arrange_track /`
  `set_track_instrument / set_track_mix / mixer_get / set_fx_slot / set_master_gain / list_plugins / load_plugin`。
- 证据：`npm run check:rack`、`node tools/dev/arrange_ui_check.mjs`（v1 迁移 → 机架 → 选择器 → 分配 → AI 热应用）。

## P3 · 素材库三页签

- 采样 / 音源 / 效果器三页签；采样树 + **真实波形**（离屏解码，非占位图）；按包筛选；
  音源卡片「＋ 入架」直达分配；效果器页签在 P4/P5 之后转为活页（引导到混音台 FX 槽）。
- 键盘可达（页签 ←→、Enter/Space、Esc 清搜索）、六态齐备、Stagger 30ms 进场。
- 证据：`npm run check:material`、`arrange_ui_check.mjs` 素材库段落（含波形像素断言与双主题截图）。

## P4 · 混音台 v1 + FX 基础设施

- 每轨一条通道条 + 主通道；推子（dB 显示 + `role=slider` + `aria-valuenow/valuetext`）、
  声像（旋转刻度）、M/S、**每通道 8 个 FX 槽**、电平表（`scaleY`，含 clip 指示）、`F9` 开合。
- 引擎侧 FX 基础设施：`FxChain`（原子槽位、bypass/wet、dry scratch、延迟释放队列 thunk）、
  `MixerGraph`（轨上链路 + 主链、`getMasterPeak`）。
- IPC：`fx.setChain / fx.getChain / mixer.setMaster / mixer.get`；levels 增加 `master`。
- 证据：`npm run check:mixer`、`arrange_ui_check.mjs` 混音台段落（19 项）、
  `engine_smoke` 的 fx/mixer/getLevels-master 段落。

## P5 · VST3 宿主

- 扫描（**异步** + `plugin.scanStatus` 轮询 + `plugin.scanCancel`，逐个上报进度）、

- 总线路由按**插件自己声明的**通道数处理（宿主不再重配 VST3 总线）。

## P6 · MM 插件平台

- **规范**：`docs/MM插件规范.md`（包结构、manifest schema、能力模型、ABI、UI 桥、错误码 MM001–MM012）。
- **校验器**：`internal/mm`（fail-closed，24 条规则 / 23 个测试）；篡改 manifest 的包被
  **MM010 哈希门禁拒绝安装**（实测）。
- **SDK + CLI**：单头文件 `mm.h`（`MM_DECLARE_PLUGIN`、`SMoothedParam`）；
  `mm new/doctor/build/validate/inspect/install/test`（`install` 能力授权 fail-closed）。
- **示例**：`examples/gain`（效果器）、`examples/synth`（乐器，128 复音正弦），
  `mm build` 产出 41.3 KB / 43.1 KB 且校验通过。
- **引擎运行时**：MM 效果器（`MmFxProcessor`）与 MM 乐器（`loadMmInstrument`）接入；
  音符路由优先级 MM → VST3 → SF2；**MM 乐器实测轨道电平峰值 0.4601**（真实 MIDI 帧驱动）。
- **参数 IPC**：`plugin.params/plugin.setParam` 支持 MM；**当前值由宿主记账**
  （`values_[]`，初值取 `paramDecl.default` 按同曲线归一化）——MM ABI 有意不提供"读当前值"。
- **UI 承载窗**：`frontend/mm-ui.html`（宿主 → 承载页 → **sandbox iframe** 三级结构；
  `mm.ready/params/setParam/paramChanged/resize/tooltip/theme`；骨架加载态；非法消息丢弃计数）。
- **AI 闭环**：`mm_create_plugin / mm_write_file / mm_build_plugin / mm_install_plugin`
  （首次编译需 `confirm=true`，源码写在 `Library/plugin-src/<id>/` 内，路径逐条校验）。
  实测：创建 → 改源码（参数改名 `AI Gain`、默认 0.35、`author.type=ai`）→ 编译（41.3 KB，校验通过）
  → 安装 → **引擎装载并读到 0.35**，`state` 显示 `slot=0 [mm] id=com.example.aitest`。
- **安装 → 注册表同步**：`soundlib.SyncInstalledMM`（kind=mm、能力清单、哈希、`origin=ai` + ✨AI 徽标、
  `classUid` = 插件 id 供承载窗打开）；`POST /api/engine/plugins/sync`、`GET /api/engine/plugins/installed`。
- **能力授权**：后端 `internal/mm/install.go` 两步式（`preview` 不落盘 → 勾选 → 安装），
  fail-closed：声明未授权拒绝、**授予未声明的能力也拒绝**（不许多授权）、重复安装拒绝、zip-slip 拒绝；
  前端在设置页「声音管理」给出**逐项勾选**界面（不做默认全选）。
- **崩溃隔离**：第三方插件（如 Krush）崩引擎 → 主程序 supervisor 自动重启引擎并提示（多次实测）。

## 缺陷修复（本周期真实发生）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 中文 IPC 文本全变 `æ\u008f\u0092ä»¶…` | JUCE `String(const char*)` 按 ASCII 解释 | `Source/Text.h` + `u8()` 包装（40 + 8 处） |
| 2 | `plugin.scan` 同步阻塞，后续请求全部超时 | 扫描在消息线程跑满 | 异步启动 + `scanStatus` 轮询 + `scanCancel` |
| 3 | 音源注册表读不到真实 SF2 预设 | 真实文件用**小写** `phdr` | `strings.EqualFold`（GeneralUser GS 269 预设） |
| 4 | **VST3 效果器入链即崩引擎** | 宿主在实例化后 `setPlayConfigDetails` 重配 VST3 总线 | 不再重配，按插件声明取总线缓冲 |
| 5 | 插件乐器电平恒为 0（**两轮误判为"未授权"**） | ① `noteOnTrack` 根本不是 IPC 方法（音符发进虚空）② 处理路径崩溃 | 改用真实 MIDI 帧 `0x04 [type][track][status][d1][d2]`；修总线 |
| 6 | 效果器被静默装成**乐器** | HTTP `/load` 从 **query** 读 `slot`，POST 的 slot 在 **body** | `slot` 改 `*int`，按 body 解析（4 处统一） |
| 7 | MM 乐器被装进 FX 槽并报"槽位序号超出范围" | Go 侧无条件带 `slot=-1`，引擎按 presence 分流 | 统一"按值判断"（`slot<0` = 乐器） |
| 8 | MM 参数界面无法显示当前值 | MM ABI 无"读当前值"（权威在宿主），宿主未记账 | 宿主 `values_[]` 记账 + `params` 输出 `value` |
| 9 | 注册表重复同步报"条目已存在" | 判重按 `Path`，而 `normalizeSource` 会改写入库形状 | 改按确定性 ID（`id@version`）判重 |
| 10 | 老工程"只剩 path"的轨无归属 | 迁移对不可解析音源直接放弃 | 建"缺失"机架条目并给 `itemId` |
| 11 | 混音台通道条色条/轨名被压成 0 高 | 纵向 flex 挤压 | `.mxr-strip > * { flex: 0 0 auto }` |
| 12 | F9 打开混音台空白 | 监听在 `document`，handler 里 `this` 是 document | 传 `self` |

**两次误判的纠正（保留记录）**：
- 把"插件乐器不出声"归因于**插件未授权**，实际是 MIDI 从未发出 + 处理路径崩溃；
- 把"应用路径装 VST3 必崩"归因于**驱动/缓存差异**，实际是我的测试脚本把任何非 2xx 当"崩"，
  而那个 400 来自真实的 `slot` 解析 bug（引擎 pid 与 `restarts` 全程未变，引擎一直活着）。

## 打磨轮补充（P7 之后）

### 新增能力

- **插件卸载**：设置页 MM 条目 🗑 → `POST /api/engine/plugins/uninstall`。
  顺序：先卸引擎里占用它的槽位 → 删安装目录 → 清注册表条目。
  引擎的槽位释放是**延迟**的（处理器进释放队列、约 500 ms 后才销毁），Windows 上
  已加载的 DLL 被文件锁占用，因此对"占用类"错误做短重试（14×300ms）；泛化的
  `permission denied` 属 ACL 问题，不重试（避免用户白等）。
- **编译作业可观测**：`mm build` 变成可轮询后台作业（阶段/耗时/日志尾部），
  `mm_build_plugin` 等 25 秒、超时给作业号，`mm_build_status` 继续查看；
  作业表有 TTL 30 分钟 + 保留最近 20 个，长会话不会只增不减。
- **`getLevels` 增加 `postLevels`**：每轨 **FX 链输出的原始峰值**（乘轨道增益之前、
  释放平滑之前）。原有的 `levels` 是"给人看的表"，混合了增益与平滑，用它做效果器
  A/B 会被这两层掩盖。
- **承载窗按插件 manifest 的 `ui` 尺寸打开**（`/api/engine/plugins/installed` 返回
  `uiWidth/uiHeight`；混音台在**面板打开时**预取，避免在 `window.open` 前发请求丢掉
  用户手势而被拦弹窗）。
- **示例补齐第三种**：`examples/filter`（状态变量低通 + 对数截止频率 + 参数平滑 +
  每声道独立状态 + 自带界面演示 postMessage 桥全量消息）。

### 缺陷与教训（补充）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 13 | 插件已装载时卸载报 `409 Access is denied` | 引擎槽位延迟释放，DLL 仍被锁 | 占用类错误短重试 |
| 14 | 编译作业表只增不减 | 未做清理 | TTL + 上限 |
| 15 | filter 示例在 18 kHz 截止时**输出全静音** | Chamberlin 形式稳定区间窄，`f` 钳到 1.4 仍越界 → 状态 NaN → 兜底清零 | 换 TPT/零延迟反馈 SVF |
| 16 | 效果器 A/B 读数与参数无关（2:1:3） | **测试自身残留状态**：前面的 fx 段落给 track0/slot0 设过 `wet=0.5` 且一直留着 → 测量里混进一半干信号 | 用例之间复位被改状态 |

**第 16 条的排查过程值得留存**：现象看起来像"引擎/插件/电平表有问题"，我逐一排除了
电平表本身（轨道增益对照 1.0→0.3543 / 0.0→0.0000 精确复现）、声部累积（panic 后
静场 0.0000）、相位叠加（单音）、平滑未收敛（末次采样）、仿射模型（解不出自洽系数）
—— 这些排除都有效，但一直漏了"**测试自己留下的状态**"这一层。复位 `wet=1.0` 后数字
立刻符合理论：

```
低通：默认截止 0.4115 / 截止 20Hz 0.0008（≈静音）/ 18kHz 0.3937（全通）
增益（0~2 范围）：默认 0.8 → 0.3937 / 增益 0 → 0.0000 / 增益 1.0 → 0.7874（恰好 2×）
```

增益 1.0 → 恰好 2× 还顺带证明了**归一化值 → 实际值的曲线映射正确**（该参数实际范围
0~2）。教训：用例之间必须复位被改过的状态，否则残留会伪装成产品缺陷 —— 与本周期
另外两次误判（把"MIDI 从未发出"当成插件未授权、把接口 400 当成引擎崩溃）同一类错误。
