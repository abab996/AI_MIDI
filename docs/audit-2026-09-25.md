## 三、缺陷与修复清单（全部已修复并通过回归）

### 高危（3）

| # | 问题 | 位置 | 修复 |
|---|---|---|---|
| H1 | **GET /api/models 可外泄已存 API Key 到任意 HTTPS 主机**：GET 分支接受 query 参数 `base_url`，空 Origin 放行，跨站 `<img>` 即可让应用携带真实密钥请求攻击者域名（SSRF+凭据泄漏） | `internal/server/handler_settings.go` | GET 仅使用已保存配置（不再接受 query 参数）；前端刷新模型列表走 POST。实测攻击载荷不再外发 |
| H2 | **engine 事务锁无界排队**：bounce（最长 20min）/applySetup 在途时，所有 `Request` 路径（设备枚举、音色加载、走带控制）无限阻塞在 `mu.Lock()`，请求自身超时不含等锁时间 | `internal/engine/client.go` | 等锁改为带 timeout 预算的 TryLock 轮询 + 死会话监听，超预算快速失败返回"引擎忙" |
| H3 | **`/api/run` SSE 无写截止时间**：客户端停止读取但不关闭时 `Fprint` 无限阻塞，handler goroutine 与连接永久泄漏（`/api/chat` 有 15s deadline，此旧路径没有） | `internal/server/handler_midi.go` | `sendSSE` 经 `http.NewResponseController` 每次设 15s 写超时（与 sseCallback 同手法） |

### 中危（7）

| # | 问题 | 位置 | 修复 |
|---|---|---|---|
| M1 | `GET /projects/{id}/download` 对任意 projectID 无条件创建常驻会话（GET 无 Origin 门槛，跨站 `<img>` 循环请求即可内存无界增长） | `handler_project.go` | 先 `project.LoadProject` 校验存在性再取会话；实测不存在项目 404 且循环攻击后服务健康 |
| M2 | open-url 前缀白名单无边界：`github.com/abab996/AI_MIDI.evil.com`（域名吞并）、`…AI_MIDI@evil.com`（userinfo）可绕过 → 开放跳转 | `handler_settings.go` | 改用 `url.Parse` 校验 host 精确匹配 + 路径边界 + 禁 userinfo；新增 9 种绕过变体测试 |
| M3 | `sanitizeKnowledgeName` 用 `filepath.Base` 静默截断：`?name=../escape.md` 实际删除/覆盖 `escape.md`（E2E 实证误删） | `handler_library.go` | 含路径分隔符或 `..` 一律拒绝，不再截断；新增 `TestLibraryRejectsPathNames` |
| M4 | **`getProjectRoot` 在 go run 模式下解析到 GOCACHE 目录**（`%LOCALAPPDATA%\go-build\<hash>-d` 在 os.TempDir() 之外）：settings/Library/projects 全线错位，表现为"读到默认设置 + 知识库不可用"（E2E 实测复现） | `internal/config/config.go` | `isTempDir` 增加 Go 构建缓存识别（GOCACHE / UserCacheDir/go-build）；新增测试；实测修复后重启即正确解析 |
| M5 | pipeline 中约 20 处 `fl.Lock()…fl.Unlock()` 非 defer：锁内 panic（畸形 tool_calls、解析异常）时锁永不释放，同项目对话后续永久卡死直至重启应用 | `internal/chat/pipeline.go`、`session.go` | 引入 `WithSessionLock`/`withFLock`（defer 释放 + panic 继续传播），全部持锁点改闭包形式 |
| M6 | supervisor 重启无熔断：引擎不可修复地秒崩时每 3s kill→重启无限循环；`consecutiveFail` 永不重置 | `internal/engine/supervisor.go` | 连续 10 次秒崩后驻留失败态（`parkUntilDone`）；会话健康存续（Ready 后 >30s）时计数清零 |
| M7 | 并发 POST /api/audio/settings 时失败回滚整单覆盖：会用旧快照抹掉另一请求刚落盘的字段（如 API Key） | `handler_audio.go` | 回滚改为"磁盘最新值 + 仅更新 audio 段" |

### 低危 / 健壮性（17）

| # | 问题 | 修复 |

## 五、遗留风险与产品决策项（未改代码）

| # | 项 | 现状评估 |
|---|---|---|
| R1 | 词法白名单不防符号链接/junction（files/download、bounce/file、素材目录） | 需本地目录写权限的攻击者（价值有限）；如需彻底关闭可加 `EvalSymlinks` 实路径校验（有性能与 Windows 兼容成本） |
| R2 | 更新包 sha256 校验可缺省（清单未附 sha256 时跳过） | 清单走固定 HTTPS 域名；建议发布流程强制附带 sha256 |
| R3 | workspace/bind 可绑定任意用户目录（黑名单仅挡系统目录） | 属设计特性（原生应用由本地用户驱动）；结合前端 XSS 可放大，建议后续评估目录白名单 |
| R4 | `/api/projects/search` 无长度/速率限制 | 本地 DoS 面有限；可加 q 长度上限（低成本） |
| R5 | `ValidateBaseURL` 对回环主机放行任意端口 | 设计支持本地推理服务（Ollama 等），保留 |
| R6 | 桌面标题栏最大化/关闭按钮未获精确点击证据 | DPI 缩放 3.0 环境下坐标估算失准；最小化按钮已功能验证，同渲染路径的其余按钮逻辑一致。建议在常规 DPI 机器上人工复核一次 |
| R7 | `read_library_file` 的"知识库不可用"提示把绝对目录路径带给模型 | 便于 AI 向用户解释原因；路径属本机信息且模型上下文不出本机，保留 |
