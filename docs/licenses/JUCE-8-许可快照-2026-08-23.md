# JUCE 8 许可快照（官网核验）

> 核验日期：2026-08-23 ｜ 来源：https://juce.com/legal/juce-8-licence/
> 用途：《JUCE音频引擎开发计划》§9 合规依据的现行条款存档。条款可能变化，采购/发布前请重新核验并更新本文件。

## 结论（与开发计划 §9 一致，已核实）

1. **JUCE 8 无 AGPL 开源选项**：许可页仅描述商业 EULA 档位与 Educational 档；
   EULA 第 2.3 条明确禁止使 Framework 受制于任何要求披露源码、衍生作品同许可、
   或允许免费再分发的开源许可证——即与本项目 Apache-2.0 主仓库不兼容，
   引擎源码必须保持闭源独立仓库。
2. **Starter 免费档收入上限为 $20,000 / 过去 12 个月**（个人档含捐赠、赞助、广告收入）。

## 档位表（官网 2026-08-23 数据）

|---|---|---|---|---|

## Starter 档关键约束

- 收入超过 $20,000 须升级档位或停止开发/分发；
- Starter 产品不得与 Indie/Pro 档构建的内容混用（不得同时持有多档）;
- 不得出售、再许可或分发 Framework 本体；
- 每个**修改引擎代码**的开发者都需要独立席位，席位不可共享（仅编译/测试不需要）。

> 备注：《音频引擎选型与架构方案》早期版本记载的"AGPLv3 免费层"为 JUCE 7 时代信息；
> 其"$800 Indie 档"数字与现行 Indie 永久授权价一致但档位结构已过时。两份文档已于 2026-08-23 统一修正。
