# AI_MIDI 编曲窗口设计文档

> 版本 v1.0 · 2026-08-22
> 本文档是「类 FL Studio Playlist 编曲窗口」的实现基准。所有实现必须同时遵守《前端设计必读.md》（物理 Q 弹动效规范）与本文档。

---

## 1. 目标与定位

在多轮对话工作台（`chat.html` 的 `#studioView`）中新增一个可展开/收起的全屏编曲窗口，提供：

- 多轨时间轴编排（MIDI clip + 音频 clip）
- 左侧项目 MIDI 文件区（拖拽到轨道）
- 每轨独立 SF2 音源加载
- 右侧本地采样素材库（自定义文件夹，拖入生成音频 clip，支持渐入渐出等编辑）
- 类 FL Studio 的播放 Transport、吸附、循环、快捷键体系
- 与 AI 对话联动（「发送给 AI」、双击 MIDI clip 跳钢琴卷帘编辑）

非目标（本期不做）：混音台（F9）、Pattern/Song 双模式、VST 插件（音源槽抽象预留）。

## 2. 现状集成基础（已核实）

| 维度 | 现状 | 复用方式 |
| :--- | :--- | :--- |
| 技术栈 | Wails：Go HTTP 后端（`internal/server`，`/api/...`）+ 原生 JS 前端（无框架） | 编曲窗口直接在 `chat.html` 扩展 |

| 音频引擎 | `soundfont.js`：`SoundFontPlayer`（SF2 二进制解析 + Web Audio 播放，内置钢琴/弦乐兜底） | **每轨一个实例**；同一 SF2 按 IndexedDB id 共享解码缓存 |

| 项目数据 | `projects/{id}/`：`midi/`、`meta.json`、`draft.txt`；`GET /api/projects/{id}` 返回 `midi_files` | 左栏 MIDI 列表数据源；编排存 `arrangement.json` |
| 上下文菜单 | `chat.js` 的 `openCtxMenu(e, menuItems)` + `.select-menu` 样式 | 轨道头/clip 右键菜单 |
| 主题 | `data-theme="parchment"(暖纸)/"dark"(暗蓝)` + 全套 CSS 令牌（`--color-primary`、`--color-accent` 等） | 编曲窗口全部走令牌 |

## 3. 总体交互方案

### 3.1 入口与展开/收起动画

- `studio-bar` 右上角 `.nav-right` 内新增按钮 `🎚 编曲`（`btn btn-secondary btn-sm`），快捷键 `F5`。
- 展开：对话工作台向上折叠 `translateY(0 → -100%)`，`0.24s cubic-bezier(0.55,0,0.85,0.36)`（Snappy Collapse）；编曲窗口 `#arrangerView` 从底部升起 `translateY(100% → 0)`，`0.42s cubic-bezier(0.22,1.2,0.36,1)`（5% 轻盈过冲，与钢琴卷帘抽屉同手感）；内部三栏 Stagger 40ms 阶梯进场。
- 收起：逆向执行；动画完全结束后才 `hidden`（无状态撕裂）。
- 全程仅 `transform/opacity`；`prefers-reduced-motion` 下降级为瞬时切换。

### 3.2 窗口布局（三栏）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：Transport(播放/停止/循环/节拍器/BPM/拍号) 吸附 缩放 撤销 │[🎚 发送给 AI] [✕] │
├──────────┬──────────────────────────────────┬────────────────┤
│ 左栏      │ 中栏轨道区                        │ 右栏素材区      │
│ MIDI 列表 │ ┌轨道头┬─时间轴标尺───────────── │ 文件夹列表      │
│ (搜索)   │ │ 名称 │ clip 内容区 (canvas)    │ 音频文件+波形   │
│ .mid 文件 │ │ M S  │                        │ (可试听/拖拽)   │
│ 可拖拽    │ │ 音量 │                        │ ＋添加文件夹    │
│          │ └──────┴───────────────────────── │                │
└──────────┴──────────────────────────────────┴────────────────┘
```

### 3.3 数据模型

```js
Arrangement = {
  version: 1,
  bpm: 120, timeSig: [4, 4],
  tracks: [Track],
  loopRegion: { startBeat, endBeat } | null
}

Track = {
  id, name, color,            // color: 8 色预设索引
  type: "instrument" | "audio",
  sf2Id: null | string,       // IndexedDB SoundLibrary id（仅 instrument）
  sf2Preset: null | string,   // 预设 id（仅 instrument）
  volume: 0.8, pan: 0,
  mute: false, solo: false,
  clips: [Clip]
}

Clip = {
  id,
  kind: "midi" | "audio",
  startBeat, lengthBeats,
  // kind === "midi"
  midiFile: "xxx.mid",        // 项目内文件名（引用，不内嵌）
  notes: [...] | null,        // 解析缓存（持久化时可省略）
  // kind === "audio"
  samplePath: "D:/…/kick.wav",// 绝对路径（须在已登记素材文件夹白名单内）
  sampleOffsetSec: 0,         // 裁剪起点
  fadeInSec: 0, fadeOutSec: 0,
  fadeInCurve: "linear" | "exp" | "sine",
  fadeOutCurve: "linear" | "exp" | "sine",
  gainDb: 0, reverse: false,
  mute: false
}
```

### 3.4 持久化

- `PUT /api/projects/{id}/arrangement`：序列化 Arrangement（剔除 notes 缓存）写入 `projects/{id}/arrangement.json`；`GET` 读取恢复。
- 自动保存：编辑操作防抖 2s 自动保存 + `Ctrl+S` 手动保存（HUD「已保存」）。

## 4. 功能模块

### A. 轨道系统
- 默认 1 条乐器轨；轨道头：颜色块、名称（双击改名）、M/S、音量滑杆、音源槽（显示 SF2 名，点击弹出：内置音色 / 音源库 / 上传 .sf2）。
- 右键轨道头：重命名 / 轨道颜色(8 色) / 加载音源(SF2) / 静音 / 独奏 / 重置音量 / 上移 / 下移 / 复制轨道(含 clip) / 删除轨道(danger)。
- 右键轨道头空白处：新建乐器轨 / 新建音频轨。
- 轨道行高可拖（轨道头下边缘），轨道头拖拽排序。

### B. 左栏 MIDI 区
- `GET /api/projects/{id}` 的 `midi_files` 渲染，支持搜索过滤、文件夹分组。
- 拖拽 .mid 到轨道头 → 在该轨第 1 小节放置 clip（乐器轨）；拖到空白轨道区 → 自动新建乐器轨；拖到 clip 区 → 落点小节处放置。

### C. 右栏素材区
- 「＋ 添加文件夹」→ Wails `SelectFolderDialog()`；路径列表持久化到 `settings.json` 新增字段 `sample_folders: []`。
- 后端新增：
  - `GET /api/samples/list?path=…`：递归扫描 `.wav/.mp3/.ogg/.flac/.aiff`，返回 `{name, relPath, sizeBytes}`（限已登记白名单前缀，防目录穿越）。
  - `GET /api/samples/file?path=…`：流式返回音频字节（同源白名单校验）。
- 前端 `AudioContext.decodeAudioData` 解码（结果缓存）→ 峰值降采样绘制波形 → 单击试听；拖入轨道创建音频 clip（长度按 BPM 换算成拍）。

### D. 音频 clip 编辑
- 左上/右上角拖拽手柄：fade-in / fade-out 时长；波形上叠加包络线。
- 右键菜单：在播放头处分割 / 转为独立副本 / 渐入渐出曲线（无/线性/指数/正弦）/ 增益(-12~+12dB) / 反向播放 / 静音 / 删除。
- 播放链：`AudioBufferSourceNode → fadeGain(包络) → clipGain → trackGain(pan) → master`。

### E. 播放引擎（Transport）
- Lookahead 调度：`setInterval(25ms)`，提前 120ms 向 AudioContext 提交精确时间戳（MIDI `noteOn/noteOff(when)`；音频 `source.start(when, offset, dur)`）。
- 每乐器轨一个 `SoundFontPlayer`（共享 SF2 解码缓存）；全部汇入 master `GainNode`。
- 走带：播放/暂停/停止、循环区间、节拍器、BPM(30-300)、拍号；播放头顶层 canvas 扫线。
- 静音/独奏：任一 solo → 仅 solo 轨出声；clip 级 mute 跳过调度。

### F. AI 联动
- 「发送给 AI」：编排摘要（轨道数/配器/段落小节/调性线索）生成中文描述，走现有 `/api/chat` SSE 发送。
- 双击 MIDI clip → `PianoRoll.openFile(projectId, midiFile, "")`，卷帘关闭后重解析刷新缩略图。

## 5. 详细交互设计（FL Studio Playlist 蓝本）

### 5.1 全局与窗口快捷键
| 按键 | 功能 |
| :--- | :--- |
| `F5` | 打开/收起编曲窗口 |
| `Esc` | 关闭编曲窗口；有弹层时优先关弹层 |
| `Space` | 播放/暂停 |
| `Ctrl+S` | 保存编排 |
| `Ctrl+Z` / `Ctrl+Alt+Z` | 撤销 / 重做 |
| `Ctrl+M` | 节拍器开关 |
| `L` | 循环开关 |
| `Home` / `End` | 播放头到开头 / 最末 clip 结尾 |

焦点规则：编曲窗口展开时接管按键；钢琴卷帘弹出时焦点移交卷帘（其 P/B/D/C、`Ctrl+T` 键盘弹奏等在卷帘内生效），关闭后交还；输入框聚焦时单键快捷键挂起。

### 5.2 工具键（对齐钢琴卷帘肌肉记忆）
| 键 | 工具 | 编曲窗口行为 |
| :--- | :--- | :--- |
| `P` | 画笔 | 点击空白轨道区创建空 MIDI clip；拖动移动 clip |
| `B` | 笔刷 | 横扫连续铺重复 clip |
| `D` | 擦除 | 点击/划过删除 clip |
| `C` | 切片刀 | 沿网格线切开 clip（MIDI/音频通用） |
| `E` | 框选 | 拉框多选 |
| `T` | 静音 | 点击 clip 静音/恢复（静音 clip 变暗+斜纹） |
| `Z` | 缩放 | 左键放大/右键缩小/拉框缩放到选区 |
| `Y` | 刮擦试听 | 时间轴按住拖动刮擦发声 |

### 5.3 编辑组合键
| 按键 | 功能 |
| :--- | :--- |
| `Ctrl+A` / `Ctrl+D` / `Ctrl+I` | 全选 / 取消选择 / 反选 |
| `Ctrl+C` / `X` / `V` | 复制 / 剪切 / 粘贴（粘贴到播放头或原轨） |
| `Ctrl+B` | 选中 clip 顺延复制到其后紧邻位置 |
| `Ctrl+G` | 合并选中 clip（同轨相邻 MIDI） |
| `Delete` / `Backspace` | 删除选中 |
| `Shift+↑/↓` | 选中 clip 移到上/下轨道 |
| `←/→`（`Ctrl` 大步进） | 按吸附粒度微移选中 clip |

### 5.4 鼠标手势
| 手势 | 行为 |
| :--- | :--- |
| 左键拖 clip | 移动（跨轨/跨小节，吸附） |
| 拖 clip 左右边缘 | 裁剪（不缩放内容） |
| 拖 clip 左上/右上角 | 渐入/渐出（音频，HUD 显示 ms 与曲线） |
| `Shift+拖拽` | 克隆副本 |
| `Alt+拖拽` | 绕过吸附微调 |
| `Ctrl+左键拖拽` | 任意工具临时拉框选 |
| 滚轮 / `Shift+滚轮` | 垂直 / 水平滚动 |
| `Ctrl+滚轮` | 以指针为锚点水平缩放 |
| 中键拖拽 | 平移视图 |
| 双击 MIDI clip | 钢琴卷帘编辑，保存后缩略图同步 |
| 双击音频 clip | clip 属性弹窗（增益/反向/归一化/信息） |
| 双击时间标尺 | 设置/清除循环区间 |
| `Ctrl+拖标尺` | 框出精确循环区间 |
| 右键划过 clip（擦除/静音工具） | 批量删除/静音 |

### 5.5 右键菜单
轨道头：`✏ 重命名 / 🎨 轨道颜色 ▸(8色) / 🎹 加载音源(SF2) ▸(内置/音源库/上传) / 🔇 静音 / 🎧 独奏 / 🔊 重置音量 / ⬆ 上移 / ⬇ 下移 / ⧉ 复制轨道 / ── / 🗑 删除轨道`
空白处：`＋ 新建乐器轨 / ＋ 新建音频轨`
clip：`🎹 钢琴卷帘编辑(仅MIDI) / ✂ 播放头处分割 / ⧉ 转为独立副本 / 🌊 渐入渐出 ▸(无/线性/指数/正弦) / 🔊 增益 ▸(-12~+12dB) / 🔄 反向(仅音频) / 🔇 静音此 clip / ── / 🗑 删除`

### 5.6 HUD 与微反馈
- 拖 clip：HUD 实时显示 `小节.拍` 落点；调 BPM/音量/渐入渐出/切工具 → `hud-pop` 0.32s Bouncy Pop。
- 按钮 `.pressed` 反馈（`fn-press` 0.35s）；轨道行进场 Stagger 40ms；播放中 clip 边缘发光（`--color-glow`）。

### 5.7 与 FL 的刻意差异
1. 右键 = 菜单而非直接删除（与本项目菜单语言一致；效率由"右键划过删除"手势补）；
2. 不做 Pattern/Song 双模式（clip 直接引用 MIDI 文件）；
3. 混音台本期不做，轨道数据结构预留 volume/pan/mute/solo。

## 6. 渲染与性能设计

| 层 | 内容 | 重绘时机 |
| :--- | :--- | :--- |
| 底层离屏 canvas | 网格、小节线、标尺 | 仅缩放/拍号/BPM 变化 |
| clip 缩略图缓存 | MIDI 卷帘缩略图、音频波形峰值图 | 仅 clip 数据变化，按 clip 复用 |
| 主 canvas | 合成各层 + clip 布局 | 仅拖拽/编辑/滚动 |
| 顶层 canvas | 播放头扫线、选框 | 每帧仅画此层 |

- 共享 SF2 解码缓存（IndexedDB id 去重）；>300MB SF2 加载前提示。
- 音频解码结果缓存 + 波形峰值预计算；超长采样分片。
- 多实例共享单一 `AudioContext`；lookahead 调度防破音。

## 10. 风险与对策

1. 多轨 SF2 内存 → 共享解码缓存 + 巨型 SF2 提示 + P4 内存水位实测。
2. 大音频解码卡顿 → 缓存 + 峰值预计算 + 分片。
3. canvas 性能 → 分层渲染（见第 6 节）。
4. 本地路径安全 → `/api/samples/*` 白名单前缀校验，防目录穿越。
