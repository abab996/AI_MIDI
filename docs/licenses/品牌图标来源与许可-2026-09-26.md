# 品牌图标来源与许可（brand-icons）

> 核验日期：2026-09-26 ｜ 来源：https://www.npmjs.com/package/@lobehub/icons-static-svg
> 用途：设置页 / 对话页的供应商与模型图标（`frontend/src/brand-icons.ts`，由
> `tools/dev/gen-brand-icons.mjs` 生成）。升级图标库版本或增删品牌时请同步更新本文件。

## 结论

1. **图标文件本身按 MIT 许可分发**（`@lobehub/icons-static-svg`，本仓库取 **v1.95.1**，
   41 个品牌）。MIT 与主仓库 Apache-2.0 兼容，可随程序一同分发，需保留版权与许可声明
   （已写在生成文件头部）。
2. **图标里的图形是各家公司的商标**，商标不随 MIT 授权转移。本项目只在"标明这是哪家
   供应商/模型"的场合使用（指名性使用），不暗示任何赞助、隶属或背书关系；不把任何品牌
   图标用作本软件自身的标识。
3. 因此**运行时不做联网加载**：图标已全部内联进 `brand-icons.js`，不向任何第三方发起
   请求，也就不涉及把用户的使用情况泄露给外部 CDN。

## 收录范围

- 供应商预设 → 品牌：见 `tools/dev/gen-brand-icons.mjs` 的 `PRESETS`
  （未收录的预设与自定义供应商回退为首字母方块）。
- 模型 ID 前缀 → 品牌：见同文件的 `MODEL_PREFIXES`；目录外的模型回退为其所属供应商的
  图标，再回退到首字母方块。

## 缺失与替代

图标库未收录 `llama.cpp`，该预设与同类自定义项走首字母方块兜底，不代用其他项目的图标
（`llamaindex` 是另一个项目，不能拿来当 llama.cpp 用）。

## 升级步骤

```bash
# 改 tools/dev/gen-brand-icons.mjs 顶部的 VERSION，然后
node tools/dev/gen-brand-icons.mjs
npm run build
```
