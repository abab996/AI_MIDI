# 通用作曲与编曲技巧

本文件为 AI 的「其他要求」功能以及所有创作任务提供通用的作曲与编曲技巧指导。

---

## 一、旋律写作

### 旋律轮廓

- 好听的旋律通常有明显的起伏（不是一条直线）
- 起始音可以低，逐步上升制造期待
- 高潮点放在乐段的 2/3 处附近
- 乐句结束音倾向于落在稳定音上（主音或属音）

### 动机发展

- 从一个小动机（2–4 个音）出发
- 重复时进行微变：移高/移低、倒影、逆行、加装饰
- 变化与统一是旋律的基本法则

### 音程控制

- 相邻音符以级进（二度）为主，穿插跳进增加趣味
- 避免连续跳进（三连跳以上会显得粗糙）
- 大跳后最好反向级进回归（"先跳后级"原则）

### 终止式设计

- 乐句结尾停在属音 → 半终止，制造"未完待续"
- 乐句结尾停在主音 → 全终止，制造"完成感"
- 乐句之间交替使用半终止和全终止

## 二、低音线写作

### 基本规则

- 低音线应保持相对平稳，避免大幅跳跃
- 优先使用和弦根音作为低音
- 低音线可以创造对位旋律（counter-melody）

### 低音线类型

| 类型 | 特征 | 效果 |
|------|------|------|
| 根音行进 | 和弦根音按顺序 | 稳定、传统 |
| 五度进行 | 根音→五度→根音 | 律动感 |
| 级进低音 | 低音声部级进 | 流畅、线性 |
| 低音模进 | 低音重复一个短动机 | 驱动力 |

### 对位低音

- 低音线也可以是一条独立的旋律
- 注意与上方声部的音程关系
- 避免与旋律声部形成平行五度/八度

## 三、织体与编配

### 织体类型

| 织体 | 描述 | 适用场景 |
|------|------|---------|
| 单音 | 只有一个旋律线 | 独唱、独奏 |
| 主调 | 旋律 + 和弦伴奏 | 流行、民谣 |
| 复调 | 多个独立的旋律线 | 赋格、卡农 |
| 支声 | 主旋律 + 微变形的平行声部 | 民族音乐 |

### 声部间距

- 相邻声部之间保持在合理音程内
- 低音与其他声部之间至少间隔一个八度或三度以上
- 避免声部交叉（上声部低于下声部）
- 避免声部超越（某声部越过相邻声部的音域）

## 四、力度与表情

### 力度术语

- `pp`（极弱）→ `p`（弱）→ `mp`（中弱）→ `mf`（中强）→ `f`（强）→ `ff`（极强）
- `cresc.`（渐强）→ `dim.`（渐弱）
- `sfz`（突强）

### 力度标记（在 note_table 中通过 velocity 体现）

| velocity 值 | 力度 |
|------------|------|
| 20–40 | pp–p |
| 40–60 | mp–mf |
| 60–80 | f |
| 80–100 | ff |
| 100–127 | 极限力度（注意真实乐器上限）|

### 表情建议

- 乐句开头稍弱（但不过分），逐渐增强
- 乐句最高音给予更强力度
- 乐句结尾可以稍弱或延长（rubato）
- 重复段落的第二次演奏可以稍强

## 五、调式色彩速查

| 调式 | 色彩关键词 | 情绪倾向 |
|------|-----------|---------|
| C 大调 | 明亮、阳光 | 欢快、自信、开阔 |
| a 小调 | 忧郁、深沉 | 悲伤、内省、严肃 |
| D 大调 | 辉煌、明亮 | 庆祝、凯旋、温暖 |
| d 小调 | 紧张、戏剧性 | 挣扎、悬念、悲壮 |
| F 大调 | 田园、宁静 | 平静、怀旧、沉思 |
| f 小调 | 黑暗、沉重 | 痛苦、绝望、阴暗 |
| G 大调 | 乡村、自然 | 轻松、质朴、热情 |
| g 小调 | 悲剧、热情 | 愤怒、痛苦、挣扎 |
| 多利亚（D Dorian） | 民谣、凯尔特 | 忧郁但温暖、坚韧 |
| 弗里吉亚（E Phrygian） | 西班牙、弗拉门戈 | 神秘、异域、紧张 |
| 利底亚（F Lydian） | 梦幻、漂浮 | 超现实、憧憬、空灵 |
| 混合利底亚（G Mixolydian） | 布鲁斯、摇滚 | 不完美感、原始力量 |
| 洛克利亚（B Locrian） | 极不稳定 | 极少使用，适合极端的实验音乐 |

## 六、曲式结构

### 常见结构

| 曲式 | 结构 | 说明 |
|------|------|------|
| AABA | A段+A段+B段+A段 | 爵士、流行经典结构 |
| ABAB | 主歌+副歌+主歌+副歌 | 流行歌曲最常用 |
| intro-verse-chorus-verse-chorus-bridge-chorus | 前奏-主歌-副歌... | 现代流行标准 |
| 12小节布鲁斯 | I-I-I-I-IV-IV-I-I-V-IV-I-I | 布鲁斯基础 |
| 通奏低音 | 主题+若干变奏 | 古典变奏曲 |
| ABA | 呈示+对比+回归 | 三部曲式 |
| 奏鸣曲式 | 呈示部+展开部+再现部 | 古典奏鸣曲 |

## 七、 MIDI 输出规范

无论何种任务，只要需要输出 note_table：

1. **格式严格**：每个音符占一行，格式为 `[note: "X", velocity: "Y", start: "Z1", end: "Z2"]`
2. **时间连续**：所有音符的 start/end 时间必须精确衔接，不能有时隙
3. **不重叠原则**：同一音名的音符在同一时间不能重叠（除非明确的和弦意图）
4. **速度值合理**：velocity 范围 0–127，建议 40–110 之间
5. **时间精度**：start 和 end 保留 2 位小数即可
6. **仅输出数据**：最终回答中不能有任何解释性文字，纯粹的 note_table 数据
