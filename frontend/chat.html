⌨ FL Studio 钢琴卷帘快捷键一览
常用工具单键（关闭键盘弹奏时有效）：
P: 画笔 (Draw) ｜ B: 笔刷 (Paint) ｜ D: 擦除 (Erase)
C: 切片刀 (Slice) ｜ E: 框选 (Select) ｜ T: 静音 (Mute) ｜ Z: 缩放 (Zoom)
🎹 电脑键盘作为 MIDI 弹奏输入：
Ctrl + T: 切换“键盘弹奏”模式。开启时：电脑键盘按键（Z~M、Q~P）直接作为 MIDI 琴键弹奏发声，单键快捷键挂起；关闭时：单键快捷键恢复生效。
力度与鼠标高级手势：
鼠标中键拖拽 / Shift + 右键拖拽: 视图平移模式 (Pan View)，直接自由拖动卷帘画布
Alt + 滚轮: 悬浮音符 / 批量调节选中音符力度 (带 HUD 提示)
Shift + 拖拽音符: 克隆复制音符副本 ｜ Alt + 拖拽: 自由微调 (绕过网格吸附)
Ctrl + 左键拖拽: 任意工具下快捷拉出选框 ｜ 右键划过音符: 极速擦除
力度窗画线/涂抹: 在下方力度窗按住拖拽划出连续力度斜坡
双击音符: 打开音符属性弹窗 (Note Properties)
常用组合键：
Ctrl + A: 全选 ｜ Ctrl + D: 取消全选 ｜ Ctrl + I: 反选
Ctrl + B: 顺延复制至下一小节 ｜ Ctrl + Q: 快速量化 ｜ Ctrl + L: 快速连奏
Alt + X: 力度缩放器 ｜ Alt + S: 扫弦工具 ｜ Alt + A: 琶音器 ｜ Alt + R: 随机化
Shift + 上/下: 半音移调 ｜ Ctrl + 上/下: 八度移调 ｜ Space: 播放/暂停

⌨ 编曲窗快捷键一览 · 参考 FL Studio
走带控制：
Space: 播放 / 暂停 ｜ Home: 回到开头 ｜ End: 跳到末尾 ｜ L: 循环选区开关
播放头与轨道导航：
← / →: 播放头按吸附步进 ｜ Shift + ← / →: 按小节步进 ｜ ↑ / ↓: 切换选中轨道
轨道操作：
M: 当前轨静音 ｜ Shift + S: 当前轨独奏 ｜ F2: 重命名当前轨道
Clip 编辑：
S: 在播放头处拆分所选 Clip ｜ Ctrl + Z / Y: 撤销 / 重做 ｜ Ctrl + C / X / V: 复制 / 剪切 / 粘贴（保持源轨道）
Ctrl + D: 原地克隆选中 Clip ｜ Ctrl + B: 向右顺延复制 ｜ Del / Backspace: 删除选中
Ctrl + A: 全选 ｜ Esc: 取消选择 / 关闭菜单
鼠标手势：
拖动 Clip: 移动（自动吸附）｜ Ctrl + 拖动: 克隆副本（FL 惯例）｜ Alt + 拖动: 临时禁用吸附
拖动 Clip 边缘: 裁剪长度 ｜ 拖入 MIDI/音频文件: 剪影指示真实落点，松手即放置
拖动 Clip 角部三角: 渐入渐出曲线 ｜ 双击 MIDI Clip: 在底部钢琴卷帘打开源文件
右键 Clip → 在此拆分: 按点击位置拆分 ｜ 播放中编辑内容立即生效
标尺下半部拖拽: 移动播放头 ｜ 标尺上半部拖拽: 拉出循环区间（双击清除）
+ / - 或 Ctrl+滚轮: 横向缩放 ｜ Shift+滚轮: 横向滚动
※ 快捷键按焦点区域生效：聊天输入框、钢琴卷帘、编排窗口各自独立，与 FL Studio 多窗口逻辑一致。单键快捷键在输入框聚焦或中文输入法组合时不触发。
