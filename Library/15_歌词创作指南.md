# 歌词创作：根据旋律写歌词

本文件指导 AI 如何为一段给定的旋律创作适配的原创歌词（而非翻译）。这是"其他要求"功能的潜在应用场景。

---

## 一、旋律与歌词的关系

歌词不是文字，是**另一个声部的旋律**。好的歌词必须与旋律的起伏完美咬合。

### 咬合原则

1. **重读音节落在强拍上**：一个词的重读音节应该对应旋律的强拍或长音
2. **一字一音 vs 一字多音**：
   - 一字一音：每个字唱一个音，清晰干脆
   - 一字多音：一个字唱多个音（转音），增加表现力
3. **词句边界对齐乐句边界**：一个完整的语义单位应该对齐一个完整的乐句

---

## 二、音节数匹配

### 基本规则

- 数清楚旋律中每个音的时值总和
- 歌词的音节数必须等于旋律的"歌唱位置"数量
- "歌唱位置" = 有足够时值的音符位置（极短的经过音通常不算）

###  syllable 计数方法

| 语言 | 音节规则 |
|------|---------|
| 中文 | 一字 = 一个音节（最规整）|
| 日语 | 一个假名 = 一个音节 |
| 英语 | 元音为核心，辅音依附 |
| 法语 | 鼻化元音、联诵使音节计数复杂 |

### 音节不足/过溢的处理

| 情况 | 策略 |
|------|------|
| 音节不足 | 添加语气词（啊、呀、哦）、重复关键词 |
| 音节过溢 | 合并音节（英文中弱读）、省略虚词、使用缩略 |

## 三、中文歌词创作

### 中文特点

- 一字一音节，天然规整
- 四声调：一（平）、二（升）、三（拐）、四（降）
- 声母 + 韵母结构，开口度各异

### 声调与旋律的关系

| 旋律走向 | 匹配声调 | 不匹配声调 | 效果 |
|---------|---------|-----------|------|
| 上行 | 二声（升）| 四声（降）| ✅ 自然 / ❌ 别扭 |
| 下行 | 四声（降）| 二声（升）| ✅ 自然 / ❌ 别扭 |
| 平稳 | 一声（平）| 三声（拐）| ✅ 自然 / ❌ 别扭 |

**注意**：声调匹配不是绝对规则，但严重不匹配会让歌词难以听清或唱出。

### 中文韵脚

- 押韵让歌词有记忆点
- 常见押韵：a（啊）、o（哦）、e（鹅）、i（衣）、u（乌）、ao/ou（凹凸韵）
- 中文歌词通常偶数句押韵（2、4、6...句）

### 中文歌词结构

```
主歌（Verse）：
- 叙事性，描述场景或故事
- 句式相对自由
- 韵脚不一定严格

预副歌（Pre-chorus）：
- 过渡段落
- 制造张力
- 韵律开始收紧

副歌（Chorus）：
- 情感核心
- 最精炼、最上口
- 严格押韵，句式规整
- 重复出现

桥段（Bridge）：
- 视角转换或情感转折
- 可以用不同的韵脚
- 通常比副歌短
```

### 中文歌词写作技巧

1. **具象化**：用具体的意象代替抽象概念
   - ❌ "我很伤心" → ✅ "雨打湿了窗台"

2. **动词优先**：歌词中的动词驱动叙事
   - "跑"、"追"、"坠"、"散" 比 "是"、"有" 更有画面感

3. **重复的力量**：关键词重复 3 次会有深刻的记忆效果
   - 第一次：陈述
   - 第二次：强调
   - 第三次：升华

4. **留白**：歌词不需要每一句都填满
   - 适当重复标题或核心词
   - 用休止（无歌词的乐句）制造呼吸

## 四、英文歌词创作

### 英文特点

- 有重读/弱读音节之分
- 词尾的 -tion, -ing, -ed 等通常弱读
- 多音节词中只有一个是重读音节

### 重读对齐

```
旋律强拍 → 单词重读音节
旋律弱拍 → 单词弱读音节

✅ "I WAN-der FULLY down the ROAD"
   强  弱  强    弱   强   弱   强
   1   &   2     &    3    &    4

❌ "i WANder FULLY DOWN the road"
   强拍上的音节不是重读，听起来不自然
```

### 英文韵脚

- AABB（双句押韵）：最常见，如 Taylor Swift 风格
- ABAB（交替押韵）：更有变化
- ABABCB（6 句段，C 句为过渡）： sophisticated

### 英文歌词结构

```
Verse（主歌）：4–8 行，叙述故事
Pre-chorus（预副歌）：2–4 行，情感积累
Chorus（副歌）：2–4 行，核心信息，重复
Bridge（桥段）：2–4 行，转折
Outro（结尾）：1–2 行，收束
```

## 五、日语歌词创作

### 日语特点

- 一假名 = 一音节，最规整
- 没有声调变化（但音节有高低）
- 长音「ー」占一拍
- 促音「っ」占一拍（不发音）
- 拨音「ん」占一拍

### 音节扩展技巧

```
不足时：
- 使用拗音（きゃ、しゅ、ちょ等，一个假名但音节紧凑）
- 添加助词（は、が、の、に等，本身有音节）

过溢时：
- 合并假名（「きれい」可以视为 2 音节或 4 音拍）
- 使用长音替代多个音节
- 省略非必要假名
```

### 日语韵脚

- あ行（あいうえお）押韵
- ん 行韵（以「ん」结尾的押韵，感伤、结束感）
- オ段韵（お、こ、そ、と、の、ほ、も、よ、ろ）——最常见的韵脚

## 六、歌词情感层次

### 情感递进模板

```
第一段主歌：客观描述，冷静
第二段主歌：加入感受，有情绪
预副歌：情绪升高，用词更强烈
副歌：直接表达，最核心的情感
桥段：反思、转折或新视角
最后副歌：情感最高点，可以用更强的措辞
```

### 情感词汇层次

| 层级 | 词汇特征 | 示例 |
|------|---------|------|
| 表面 | 客观描述词 | 天空、街道、风、雨 |
| 感受 | 感官词 | 冰冷、刺痛、温暖、刺痛 |
| 情感 | 情绪词 | 孤独、渴望、释然、愤怒 |
| 核心 | 抽象概念 | 自由、归属、失去、永恒 |

好的歌词从"表面"逐步深入到"核心"。

---

## 七、歌词创作的通用规则

1. **少用抽象词**："爱"、"痛"、"自由" 等词太抽象，用具体意象表达
   - ❌ "我好想你"
   - ✅ "你留下的杯子还放在窗边"

2. **避免陈词滥调**："心碎"、"泪如雨下"、"燃尽一切" 已经被用烂了
   - 寻找独特的表达方式

3. **保持一致性**：一首歌的用词风格应该统一
   - 如果用了"海浪"的意象，不要突然跳转到"地铁"

4. **副歌要"好记"**：副歌的每一句应该能独立成句，并且容易记

5. **留白**：不是每个音符都要配字
   - 长音可以一个字拖住
   - 短音可以不填词（用啦、啊等衬词）

6. **避免拗口**：在唱之前，默读一遍歌词
   - 如果读起来不顺口，唱起来一定更别扭
