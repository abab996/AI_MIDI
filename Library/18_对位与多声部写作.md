# 对位与多声部写作

本文件指导 AI 如何写作多条独立旋律线（复调织体），涵盖卡农、赋格、合唱等多声部技术。

---

## 一、什么是复调织体

### 主调 vs 复调

| 织体 | 特征 | 示例 |
|------|------|------|
| 主调（Homophonic） | 一条旋律 + 和弦伴奏 | 流行歌、民谣 |
| 复调（Polyphonic） | 多条独立旋律线交织 | 赋格、卡农、赋格 |
| 支声（Heterophonic） | 一条主旋律 + 微变形的平行声部 | 民族音乐、即兴 |

### 复调的美学价值

- 多个旋律同时进行，每条线都有意义，互相丰富
- 听众可以"挑着听"任何一条线
- 织体更厚实、更有层次
- 各线之间的音程关系制造和谐或张力

## 二、卡农（Canon）

### 卡农的定义

一个旋律（Subject）在不同声部中以相同节奏型依次进入，每个声部延迟一小节。

### 卡农的规则

1. 所有声部使用相同的旋律（或非常相似的旋律）
2. 各声部在不同时间点进入
3. 进入的间隔通常为一个完整乐句的长度
4. 低声部最先进入，高声部最后进入

### 常见卡农间隔

| 间隔 | 名称 | 效果 |
|------|------|------|
| 1 小节 | 紧接卡农 | 密集、催眠 |
| 2 小节 | 标准卡农 | 最平衡 |
| 4 小节 | 松散卡农 | 舒缓、庄严 |
| 倒影卡农 | 第二声部是倒影 | 镜像感 |

### 卡农的 note_table 写法

```
声部 1（先进入）：
[note: "C4", velocity: "85", start: "1", end: "1.5"]
[note: "E4", velocity: "85", start: "1.5", end: "2"]
[note: "G4", velocity: "85", start: "2", end: "2.5"]
[note: "C5", velocity: "85", start: "2.5", end: "4"]

声部 2（延迟 1 小节进入，即从 start=5 开始）：
[note: "C4", velocity: "75", start: "5", end: "5.5"]
[note: "E4", velocity: "75", start: "5.5", end: "6"]
[note: "G4", velocity: "75", start: "6", end: "6.5"]
[note: "C5", velocity: "75", start: "6.5", end: "8"]

声部 3（延迟 2 小节进入，即从 start=9 开始）：
[note: "C4", velocity: "65", start: "9", end: "9.5"]
...
```

### 卡农的声部音量层级

- 先进入的声部（通常是低音区）：稍弱，像背景
- 最后进入的声部（高音区）：稍强，像焦点
- 中间声部：中等力度

## 三、赋格（Fugue）

### 赋格的定义

一种严格的复调形式，有一个"主题"（Subject）和一个"答题"（Answer），通过严格的对位规则交织。

### 赋格的基本结构

| 部分 | 名称 | 说明 |
|------|------|------|
| 第一次主题呈现 | 呈示部 | 声部 1 演奏主题，声部 2 演奏答题 |
| 答题 | Answer | 主题在属调上的移调（纯五度关系）|
| 对题 | Countersubject | 与主题同时出现的第二旋律线 |
| 中间段 | Middle Entries | 主题在更多调上出现 |
| 结尾 | Final Entry | 主题在主调上回归，完成 |

### 赋格的答题规则

- 答题 = 主题在纯五度（上方或下方）上的移调
- 真实答题：严格移调，音程完全一致
- 变化答题：略有调整以适应和声进行

```
主题（C 大调）：
C4 – E4 – G4 – A4 – B4 – C5

答题（G 大调，纯五度上方）：
G4 – B4 – D5 – E5 – F#5 – G5
（每个音升高纯五度）
```

### 赋格的音程规则

在复调写作中，同时发声的音符之间要避免不协和音程：

| 允许 | 条件 |
|------|------|
| 纯一度/八度 | 同音或隔八度（协和）|
| 纯五度 | 协和 |
| 大三度 | 协和 |
| 小三度 | 协和 |
| 大六度 | 协和 |
| 纯四度 | 在上方声部可接受 |
| 小二度 | ❌ 作为旋律音程可，但作为和声音程（同时发声）需要立刻解决 |
| 大七度 | ❌ 需要立刻解决 |
| 增四/减五 | ❌ 需要立刻解决（除非在特定风格中）|

### 对位中的解决规则

不协和音程（小二度、大七度、增四/减五）出现在强拍上时，**下一拍必须解决**到协和音程。

```
❌ 错误的：
声部 1：C4（第 1 拍）
声部 2：C#4（第 1 拍）
→ 小二度，强拍上的不协和，且没有解决

✅ 正确的：
声部 1：C4 → D4（第 1 拍 → 第 2 拍）
声部 2：C#4 → C4（第 1 拍 → 第 2 拍）
→ 第 1 拍是小二度（不协和）→ 第 2 拍解决到纯一度（协和）
```

## 四、两声部对位写作

### 规则 1：反向运动优先

两个声部向相反方向运动，是最自然、最动听的对位方式。

```
✅ 反向：
声部 1：C4 → E4（上行）
声部 2：G4 → E4（下行）

✅ 斜向（一个不动一个动）：
声部 1：C4 → C4（保持）
声部 2：E4 → G4（上行）

⚠️ 同向（两个都上行/下行）：
声部 1：C4 → D4
声部 2：E4 → F#4
→ 如果形成平行五度或平行八度 → ❌ 禁止
```

### 规则 2：禁止平行五度/八度

两个声部以纯五度或纯八度同向移动是最严重的对位错误。

```
❌ 平行五度：
声部 1：C4 → D4
声部 2：G3 → A3
（C–G → D–A，都是纯五度，且同向移动）

❌ 平行八度：
声部 1：C4 → D4
声部 2：C3 → D3
（C–C → D–D，都是纯八度，且同向移动）
```

### 规则 3：声部间距

- 相邻声部之间保持在三度到八度之间
- 超过八度称为"超开放"，需要谨慎使用
- 小于三度称为"声部交叉"，通常避免

### 规则 4：旋律线各自完整

每条声部应该：
- 有自己的音域（不是都在同一个八度）
- 有自己的节奏型（不是完全同步）
- 有自己的乐句（有起点、高点、终点）

## 五、多声部写作模板

### 模板 A：三声部卡农

```
声部 1（低音区，C3–G4，先进入）：
动机：C4 – D4 – E4 – G4 – A4 – G4 – E4 – C4

声部 2（中音区，C4–G5，延迟 2 拍进入）：
同样的旋律，从 C4 开始

声部 3（中高音区，C4–G5，延迟 4 拍进入）：
同样的旋律，从 C4 开始
```

### 模板 B：二重唱式（两个独立旋律）

```
声部 1（旋律 A，C4–G4）：
C4 – E4 – G4 – C5 – B4 – G4 – E4 – C4

声部 2（旋律 B，G3–D4，节奏错开）：
G3 – _ – B3 – D4 – G4 – _ – B3 – G3
（节奏互补，不是完全同步）
```

### 模板 C：四部和声（SATB）

```
Soprano（高音，C4–C6）：旋律线，最活跃
Alto（中音，G3–E5）：和声填充，节奏与 S 略有不同
Tenor（次中音，C3–A4）：和声内声部，平稳
Bass（低音，E2–C4）：低音行进
```

### 模板 D：赋格呈示部

```
声部 1（主题，C4–G4，第 1–2 小节）：
C4 – E4 – G4 – A4 – B4 – C5 – B4 – A4

声部 2（答题，G4–D5，第 3–4 小节，纯五度上方）：
G4 – B4 – D5 – E5 – F#5 – G5 – F#5 – E5
（答题后带对题）

声部 3（主题，C4–G4，第 5–6 小节，回到主调）：
C4 – E4 – G4 – A4 – B4 – C5 – B4 – A4

声部 4（答题或主题，第 7–8 小节）：
继续发展...
```

## 六、多声部在 note_table 中的表达

在多声部输出中，每个音符必须标注清晰的声部标识：

```
声部通过以下方式区分：
1. velocity 差异：旋律声部最高，伴奏声部较低
2. 音区差异：各声部在不同音区
3. 节奏差异：各声部有不同的 start/end 时间
4. 如有需要，可以在 note 字段中用前缀标记，但更推荐靠音区和节奏自然区分
```

### 多声部的 start/end 时间设计

| 策略 | 说明 |
|------|------|
| 独立节奏 | 各声部按自己的节奏型独立运动 |
| 同时起 | 某些关键点各声部同时发声（和弦点）|
| 错开进入 | 卡农式：各声部在不同时间进入 |
| 此起彼伏 | 一个声部休止时另一个发声（避免同时满）|

## 七、复调织体的音区分配

```
4 声部标准分配：
声部 4（最高）：C4–C6（旋律/主题）
声部 3：G3–E5（和声上方）
声部 2：C3–A4（和声内声部）
声部 1（最低）：E2–C4（低音/答题）

3 声部标准分配：
声部 3（最高）：C4–C6
声部 2（中间）：G3–E5
声部 1（最低）：C2–G4

2 声部标准分配：
声部 2（高）：C4–C6
声部 1（低）：C3–G4
（间距一个八度左右）
```

---

## 八、复调织体的输出规范

当 AI 需要输出多声部 note_table 时：

1. 所有声部合并到同一个 note_table 列表中
2. 每个音符标注其声部角色（通过音区和力度自然体现）
3. 各声部的时间线不能重叠混乱（要有清晰的节奏逻辑）
4. 不协和音程只能短暂出现，必须解决到协和音程
5. 禁止平行五度和平行八度
6. 各声部的乐句边界可以不同步，但要整体协调
