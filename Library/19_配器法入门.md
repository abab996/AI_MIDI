# 配器法入门：音符到乐器的映射

本文件指导 AI 如何将 note_table 中的音符合理地分配给不同乐器，让输出的 MIDI 经过音源播放后听起来真实、合理。

---

## 一、为什么配器法重要

AI 输出的 note_table 只有音名、力度和时间，但没有"哪个乐器弹哪个音"的概念。如果没有配器指导：

- 旋律跑到贝斯的音区 → 听起来像低音在唱歌
- 高音区的和弦填充 → 听起来像小提琴在弹琶音
- 所有声部用同样的力度 → 听起来像一台电子琴

配器法让 AI 知道：
- 这个音域适合什么乐器
- 这个节奏型适合什么乐器
- 这个力度水平适合什么乐器

## 二、常见乐器的音域与特征

### 人声

| 声部 | 音域（MIDI） | 音名范围 | 特征 |
|------|------------|---------|------|
| 男低音（Bass） | 41–66 | E2–G4 | 低沉、浑厚 |
| 男中音（Baritone） | 45–69 | A2–A4 | 温暖、有磁性 |
| 男高音（Tenor） | 48–72 | C3–C5 | 明亮、有力 |
| 女低音（Alto） | 55–79 | G3–G5 | 柔和、丰满 |
| 女中音（Mezzo） | 57–81 | A3–A5 | 温暖、灵活 |
| 女高音（Soprano） | 60–84 | C4–C6 | 明亮、穿透力 |

**注意**：人声最适合在中音区（C3–C5），超出这个范围会吃力。超过 C6 的女高音和低于 G2 的男低音都需要专业训练。

### 键盘乐器

| 乐器 | 音域 | 特征 |
|------|------|------|
| 钢琴 | A0–C8（21–108） | 最宽音域，力度响应宽广 |
| 电钢琴 | E1–C7（40–96） | 比钢琴窄，音色固定 |
| 风琴 | C2–C6（36–84） | 持续音，滑音变化 |
| 合成器 Pad | 灵活 | 长音铺底，滤波器变化 |

**钢琴织体分配**：
- 右手（旋律）：C4–C6
- 左手（伴奏）：C2–C4
- 右手和左手之间留出 C3–C4 的间隙（或让左手偶尔进入 C3）

### 吉他

| 类型 | 音域 | 特征 |
|------|------|------|
| 吉他（6 弦标准） | E2–E4（40–76） | 低音 E2，高音 E4 |
| 吉他（高把位旋律） | G3–E5（55–88） | 高把位 solo |

**吉他织体特征**：
- 开放和弦音域低（C2–G3）
- 高把位旋律在 G3–E5
- 分解和弦在 G2–E4
- 吉他不太适合低于 E2 的音

### 贝斯

| 类型 | 音域 | 特征 |
|------|------|------|
| 电贝司（4 弦标准） | E1–G4（32–76） | 低音根音 + 偶尔旋律 |
| 五弦贝司 | B0–C5（35–84） | 更低、更灵活 |
| 合成 Bass | 灵活 | 灵活，常用于电子音乐 |

**贝司写作规则**：
- 主功能：每拍或每小节弹根音
- 不频繁跳跃，以级进为主
- 偶尔可以在强拍上弹五度（根音 + 纯五度）
- 贝司音符的力度应该偏高（80–110），因为低频需要更多能量才能被听到

### 弦乐

| 声部 | 音域（MIDI） | 音名范围 | 特征 |
|------|------------|---------|------|
| 小提琴 | 55–103 | G3–G7 | 明亮、擅长快速跑动 |
| 中提琴 | 48–84 | C3–C7 | 温暖、中音区 |
| 大提琴 | 36–72 | C2–C6 | 深沉、也可演奏旋律 |
| 低音提琴 | 24–72 | C1–C6 | 最深沉、持续低音 |

**弦乐织体分配**：
```
第一小提琴（旋律）：G4–E6（79–88），最活跃
第二小提琴（和声）：D4–B5（62–83），填充中高区
中提琴（内声部）：G3–D5（55–74），填充中音区
大提琴（低音）：C2–G4（36–67），根音 + 偶尔旋律
低音提琴（持续低音）：E1–C3（28–48），持续根音
```

### 铜管乐器

| 乐器 | 音域（MIDI） | 音名范围 | 特征 |
|------|------------|---------|------|
| 小号 | 55–81 | G3–G6 | 明亮、辉煌 |
| 圆号 | 34–77 | E2–G5 | 温暖、圆润 |
| 长号 | 40–72 | E2–C6 | 厚重、有滑音 |
| 大号 | 28–58 | E1–Bb4 | 最低沉的铜管 |

**铜管写作规则**：
- 铜管乐器擅长强力度（ff 以上）
- 铜管不适合太密的音符（管乐器有换气限制）
- 小号和圆号的音区越高越明亮
- 长号可以用滑音（glissando）增加表现力

### 木管乐器

| 乐器 | 音域（MIDI） | 音名范围 | 特征 |
|------|------------|---------|------|
| 短笛 | 74–102 | D5–E7 | 最高、最尖锐 |
| 长笛 | 60–96 | C4–C7 | 明亮、灵活 |
| 双簧管 | 58–91 | A3–A6 | 鼻音、忧郁 |
| 单簧管 | 50–94 | D3–D7 | 温暖、宽广 |
| 巴松（大管） | 34–75 | E2–D6 | 低沉、幽默 |
| 萨克斯 | 36–88 | C2–E7 | 灵活、表现力强 |

### 打击乐

| 类型 | 特征 | note_table 中的表达 |
|------|------|-------------------|
| 底鼓（Kick） | 低频重击 | 极低音区（C1–G2），短时值，高力度 |
| 军鼓（Snare） | 中频脆响 | 中低音区（C3–G4），极短时值 |
| 踩镲（Hi-hat） | 高频金属感 | 高音区（C5–C6），极短时值 |
| 通鼓（Tom） | 中低音共鸣 | 低–中音区，中等时值 |
| 镲（Cymbal） | 长衰减金属声 | 高音区，长时值 |

## 三、配器组合模板

### 模板 A：钢琴独奏

```
右手（旋律）：C4–C6，中等力度
左手（伴奏）：C2–C4，低力度
织体：分解和弦 + 旋律
```

### 模板 B：钢琴 + 弦乐

```
钢琴右手：C4–C6，中力度
钢琴左手：C2–C4，低力度
第一小提琴：G4–D6，旋律叠加或独立旋律
大提琴：C2–G4，低音线
```

### 模板 C：吉他弹唱

```
吉他：C2–G4，分解和弦节奏型
人声（男）：C3–C5，主旋律
人声（女）：C4–C6，和声（可选）
```

### 模板 D：爵士小乐队

```
钢琴：和弦节奏 + 偶尔 solo
贝司：E1–G4，walking bass
鼓：底鼓 + 军鼓 + 踩镲
萨克斯/小号：旋律 solo
```

### 模板 E：管弦乐队

```
第一小提琴：G4–E6，主旋律
第二小提琴：D4–B5，和声
中提琴：G3–D5，内声部
大提琴：C2–G4，低音 + 偶尔旋律
低音提琴：E1–C3，持续低音
长笛：C5–C7，高音点缀
圆号：G3–G5，和声支撑
```

### 模板 F：电子音乐

```
合成器 Lead：C3–C6，旋律
合成器 Pad：C3–C5，长音铺底
合成器 Bass：C1–C3，低音线
鼓机：四四拍底鼓 + 踩镲
```

## 四、配器中的音区分配原则

### 原则 1：音域安全

每件乐器只在自身舒适音区内演奏：

```
钢琴：全音域 ✅，但左手不要弹到 C5 以上
吉他：E2–E4 ✅，E4 以上非常吃力
小提琴：G3–G7 ✅，G7 以上极难
人声男：C3–C5 ✅，C5 以上很吃力
贝司：E1–G4 ✅，G4 以上失去低音特征
```

### 原则 2：音区互补

不同乐器使用不同音区，避免重叠：

```
✅ 好的分配：
吉他（C2–G3） + 钢琴右手（C4–G5） + 小提琴（G4–D6）
三个乐器在三个不同的音区

❌ 不好的分配：
吉他（C3–G4） + 钢琴右手（C4–G5）
中音区重叠，浑浊
```

### 原则 3：音区分层

```
底层（C1–C3）：贝司、大提琴、低音提琴
中低层（C3–C4）：钢琴左手、吉他低音、中提琴
中层（C4–C5）：人声、钢琴右手、小提琴、中提琴
中高层（C5–C6）：小提琴、长笛、钢琴右手高音区
高层（C6+）：短笛、小提琴高音区
```

### 原则 4：中间留白

相邻层次之间最好有间隙：

```
✅ 好的：
贝司：C1–G2
吉他：G2–G4
人声：C4–C5
小提琴：G4–D6
（每个区间之间都有重叠但不完全重合）

❌ 不好的：
贝司：C1–C4
吉他：C2–C5
人声：C3–C6
（所有乐器的音域大面积重叠，浑浊）
```

## 五、特殊技法标记

当 AI 需要使用乐器特殊技法时，在 note_table 中用以下方式表达：

| 技法 | 乐器 | note_table 中的体现 |
|------|------|-------------------|
| 滑音 | 长号、人声 | 密集的半音经过音符，极短时值 |
| 颤音 | 弦乐、长笛 | 相邻音的快速交替，极短时值 |
| 拨弦 | 吉他、竖琴 | 短时值 + 较低力度 |
| 强音（ marcato） | 铜管、弦乐 | 较高力度 + 略长的时值 |
| 弱音 | 铜管 | 较低力度 + 较长的持续音 |
| 泛音 | 弦乐 | 高音区 + 极轻力度 |
| 闷音 | 吉他 | 短时值 + 较低力度 |
| 延音 | 钢琴 | 长时值 + 力度递减 |
| 断奏（staccato） | 所有乐器 | 极短时值（原时值的 1/4–1/2）|
| 连奏（legato） | 所有乐器 | 音符之间无缝衔接 |
