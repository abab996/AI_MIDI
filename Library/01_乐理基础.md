# 乐理基础

本文件为 AI 助手提供基础乐理知识，作为所有音乐创作任务的常识底库。

---

## 一、音高与音名

- 音名顺序：C D E F G A B（半音阶对应 0–11）
- 升降号：`#` 升半音，`b` 降半音
- 等价音名：B# = C、Cb = B、E# = F、Fb = E
- MIDI 编号：C4 = 60，中央 C，每八度差 12

### 常见音域参考

| 乐器/人声 | 大致范围 |
|-----------|---------|
| 钢琴 | A0–C8（MIDI 21–108） |
| 小提琴 | G3–E7 |
| 吉他（标准调弦） | E2–E6 |
| 男高音 | C3–C5 |
| 女高音 | C4–C6 |
| 低音 | E2–E4 |

## 二、音程

- 纯一度、小二度、大二度、小三度、大三度、纯四度、增四/减五、纯五度、小六度、大六度、小七度、大七度、纯八度
- 协和音程：纯一度、纯四、纯五、纯八（以及大/小三度在特定语境下）
- 不协和音程：小二、大七、增四/减五（需要解决）
- 音程转位后度数相加 = 9，性质互补（大↔小，纯↔纯，增↔减）

## 三、调式与音阶

### 大调音阶（自然大调）

全–全–半–全–全–全–半

### 小调音阶

- 自然小调：全–半–全–全–半–全–全
- 和声小调：自然小调 + 升 VII 级（导音升高）
- 旋律小调：上行时升 VI、VII 级；下行还原

### 中古调式（教会调式）

以 C 大调为基准：

| 调式 | 起始音级 | 特征 |
|------|---------|------|
| Ionian（伊奥尼亚） | C | 大调 |
| Dorian（多利亚） | D | 小调 + 自然六度 |
| Phrygian（弗里吉亚） | E | 小调 + 小二度开头 |
| Lydian（利底亚） | F | 大调 + 升四度 |
| Mixolydian（混合利底亚） | G | 大调 + 小七度 |
| Aeolian（爱奥利亚） | A | 自然小调 |
| Locrian（洛克利亚） | B | 小调 + 减五度 |

## 四、节奏与时值

### 常见时值

- 全音符 = 2 拍（4/4 拍）
- 二分音符 = 1 拍
- 四分音符 = 1/2 拍
- 八分音符 = 1/4 拍
- 十六分音符 = 1/8 拍
- 三十二分音符 = 1/16 拍
- 附点音符 = 原时值的 1.5 倍

### 拍号含义

- `4/4`：每小节 4 拍，四分音符为一拍
- `3/4`：每小节 3 拍，华尔兹
- `6/8`：每小节 6 拍（两拍组），八分音符为一拍
- `2/4`：每小节 2 拍，进行曲

## 五、常用术语

| 术语 | 含义 |
|------|------|
| 级进 | 相邻音高之间移动（二度） |
| 跳进 | 超过二度的音高移动 |
| 和弦 | 三个或以上音高同时发声 |
| 转位 | 和弦音以非根音为最低音 |
| 属和弦 | 调式的第五级和弦（V） |
| 下属和弦 | 调式的第四级和弦（IV） |
| 导音 | 调式的第七级音，倾向于主音 |
| 正格终止 | V → I 的终止 |
| 变格终止 | IV → I 的终止 |
| 半终止 | 在属和弦上结束乐句 |
| 终止四六 | I 和弦的第二转位，用于终止前装饰 |
