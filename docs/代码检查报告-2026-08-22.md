## 〇-B、第五轮：音频混乱 + 布局调整 + 框架调研（21:00–21:10）

### 1. 轨道上 MIDI 文件播放"混乱卡顿"——根因与修复
| 根因 | 影响 | 修复 |
|------|------|------|
| `midi_parse.js` 的 note-on/off 配对表**跨轨道共享** | 多轨 MIDI 同音高互相错配 → 音符长度错乱、大量重叠长音（一堵声音墙） | 配对表移入每条 MTrk 内部独立 |
| note-on 只按音高键控、忽略通道 | 不同通道的同音高互相覆盖/错切 | 键改为 `通道<<7 \| 音高` |
| sysex (F0/F7) 事件直接 `break` | 轨道中段一个 sysex 丢弃其后全部音符 → 大面积错位 | 按长度字段跳过 |
| 调度心跳（25ms）里每个音符每次都走正则解析音名 | 数千音符工程每秒数十万次正则 → 卡顿 | 引擎内按音名记忆化 |

已知残留限制：MIDI 文件的 **tempo 变化事件被忽略**（统一按编曲窗 BPM 播放）——选型 @tonejs/midi 可解决。

### 2. 「＋ 新建轨道」按钮移至左侧轨道头列
原在行右侧的编排区，现位于左侧轨道头格子内（与 Track 头同宽同风格，随横向滚动 sticky 固定），点击行为不变。已实测：点击后正常新增轨道。

### 3. 附带发现并修复：任务面板永久自动弹出盖住档案库右侧按钮
自动化测试发现「＋ 新建档案」「主题」按钮被拦截——根因是 `tasks.json` 残留指向已删除项目的孤儿任务（needs_confirmation），任务面板因此每次启动自动展开。修复：删除项目时同步清除其全部任务（`TaskPurgeProject`）；启动加载时丢弃项目目录已不存在的孤儿任务。已实测按钮恢复可点、面板不再自动弹出。

## 四、性能优化

### 后端
- settings.json：内存缓存（写穿 + mtime/size 校验）——此前每个请求（含每次音频白名单校验）都读盘解析。
- 项目 index.json：内存镜像（saveIndexLocked 写穿；ListProjects 返回副本防污染）——任务 2s 轮询不再每 2s 读盘。
- 项目搜索：按 history 文件缓存消息列表（mtime 失效）——逐键全量扫描 → 命中缓存仅 stat。
- TaskMarkRead：保存 300ms 防抖（整项目标已读不再逐任务全量写盘）。
- 任务轮询：前端空闲（无进行中/待确认）2s → 10s 自适应。
- 上传 MIDI：校验与音符表共用一次解析。
- 移动文件：ScanMidiFilesKeepNotes 保留 note_table（此前直接清空）。
- 静态资源：HTML no-store / 文本资源 60s 缓存 + gzip（-browser 模式刷新不再全量重传 ~370KB）。
- 闪屏：像素重采样直访 Pix 数组（NRGBA 手动预乘）；DOM 就绪即提前关闭（1400ms 变上限）；删除 theme.js 死闪屏代码。
- 安全：GET /api/settings 的 api_key 脱敏返回；PUT/模型列表对掩码值保持已存密钥（顺带修复了"保存即清空密钥"的潜在 bug）；CORS 由 `*` 收紧为本机回环来源。

### 前端
- **钢琴窗播放调度重构**：rAF 逐帧扫全部音符 + ±0.05 拍窗口 + setTimeout 停音 → **AudioContext 时钟 25ms 心跳 / 150ms lookahead 精确调度**（高 BPM 不再丢音符，后台标签不再哑火）；rAF 只画播放头；循环回绕按段展开。
- **共享单例 AudioContext**（新 audio_context.js）：synth / soundfont / audio_engine 统一（3→1），跨引擎调度同一时间轴。
- **SF2**：新增 pbag/pgen/inst/ibag/igen 最小 zone 链解析——按**键区间**选采样（修复旋律预设串到鼓组采样；缺块文件回退旧行为）；activeVoices 改 voice 列表 FIFO（同音重叠不再互相顶掉/漏停循环采样）；synth 同步改造；内置音色合成（~120 万次 sin）移出首屏、首次使用才生成。
- **钢琴窗渲染热路径**：音名→音高记忆化（不再逐音符正则）；选择集 >8 时逐帧建 Set；**左缘剔除 bug 修复**（此前视口左侧音符每帧都在画）+ 幽灵轨同款剔除；拖拽/力度画笔 render rAF 合帧（scheduleRender）；画布 resize 尺寸未变即跳过 + 拖拽合帧（顺带把 scale 换 setTransform 更稳）。
- **编曲**：mute/solo 切换定点刷新按钮态（不再全量重建轨道 DOM）。
- chat.html 14 个脚本加 defer；音源库列表改游标读取（不再一次性物化全部 SF2 ArrayBuffer）。
