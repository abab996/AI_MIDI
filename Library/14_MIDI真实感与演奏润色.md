# MIDI 演奏真实感与润色技巧

本文件指导 AI 如何让输出的 MIDI 听起来像真人演奏而非机械播放，涵盖力度设计、时间微调、音符连贯性等实用技巧。

---

## 一、力度设计：从"全一样"到"有呼吸"

### 问题：AI 常见错误

AI 经常给所有音符差不多的力度值（如全部 velocity: "80"），导致 MIDI 听起来像节拍器。

### 解决方案：力度曲线

一段好听的旋律，力度应该像呼吸一样有起伏：

```
乐句开头：稍弱（mf，60–70），像深吸气
乐句中段：逐渐增强（f，75–85），像呼气
乐句高点：最强（ff，90–100），像爆发
乐句收尾：稍弱（mp，55–65），像余韵
```

### 不同角色的力度层级

| 声部/角色 | 力度范围 | 说明 |
|-----------|---------|------|
| 主旋律 | 85–105 | 最突出 |
| 和弦伴奏 | 55–75 | 支撑但不抢戏 |
| 转音装饰 | 40–60 | 轻柔的花腔 |
| 低音（贝斯） | 80–100 | 低频需要更大力度才能被听到 |
| 打击乐 | 90–127 | 最突出 |

### 力度微调规则

1. **强拍稍强**：正拍（1、3）的力度比弱拍高 5–15
2. **长音稍弱**：时值超过 1 拍的音符，力度可以略微降低（模拟自然衰减）
3. **高音稍弱**：在高音区的长音不需要太强的力度（高频本身突出）
4. **重复音递增**：同一个音连续出现时，第二次可以稍强
5. **切分音加重**：切分位置的重音需要额外强调

```
示例力度序列（一条旋律）：
音符 1（强拍）: vel 90
音符 2（弱拍）: vel 75
音符 3（强拍）: vel 85
音符 4（弱拍）: vel 70
音符 5（强拍，高点）: vel 100
音符 6（弱拍）: vel 80
音符 7（长音，2 拍）: vel 75 → 65（递减）
```

## 二、时间微调：Humanization

### 问题：AI 的时间太精确

AI 输出的音符 start/end 往往是对齐到绝对网格的，像机器演奏。

### 解决方案：微小的时间偏移

真人演奏不会绝对精确地卡在节拍上，有一些自然的偏差：

| 类型 | 偏移量 | 效果 |
|------|--------|------|
| 正常微调 | ±0.01–0.03 拍 | 轻微的人味 |
| 切分重音 | 提前 0.02–0.05 拍 | 抢拍感，更有律动 |
| 延留音 | 延后 0.02–0.05 拍 | 慵懒感、拖拍 |
| 三连音 | 精确但非线性 | 流动感 |

### 何时提前、何时延后

```
提前（抢拍）：
- 切分音符
- 节奏型中的反拍重音
- 制造紧迫感的乐段

延后（拖拍）：
- 蓝调/爵士乐句
- 慵懒、性感的段落
- 乐句结尾的最后一个音

正常：
- 强拍上的和弦音
- 节奏型的基本骨架
- 古典风格
```

### 具体偏移量参考（BPM 120 为例）

| 偏移 | 毫秒 | 听感 |
|------|------|------|
| 0.01 拍 | ≈12.5ms | 几乎不可闻 |
| 0.02 拍 | ≈25ms | 轻微的人味 |
| 0.05 拍 | ≈62.5ms | 明显的拖/抢拍 |
| 0.1 拍 | ≈125ms | 切分感，但不要太夸张 |

**注意**：偏移不要超过 0.1 拍（约 125ms），否则会明显跑调。

## 三、音符连贯性：Legato 与 Portamento

### 问题：音符之间有缝隙

AI 经常让音符的 end 时间比下一个音符的 start 时间早，留下无声的缝隙，听起来断断续续。

### 解决方案：Legato（连奏）

```
❌ 不好的：音符 A 在 1.0 结束，音符 B 在 1.1 开始 → 0.1 拍空隙
✅ Legato：音符 A 在 1.05 结束，音符 B 在 1.05 开始 → 无缝衔接
✅ 更自然：音符 A 在 1.02 结束，音符 B 在 1.0 开始 → 轻微重叠（更真实）
```

### Legato 的应用场景

| 场景 | 处理方式 |
|------|---------|
| 旋律级进（相邻音） | 轻微重叠（–0.02 到 0），完全连贯 |
| 旋律跳进 | 可以有小缝隙（0.01–0.03），但不要太明显 |
| 同音重复 | 略微重叠，模拟真实连弓/连奏 |
| 和弦音 | 可以整齐开始，但和弦音之间可以轻微错开 |

### 滑音（Portamento / Glide）

在两个音符之间加入一个极短的滑音连接：

```
C4 → E4（跳进）：
没有滑音：C4 end=1.0, E4 start=1.1（有明显的音高跳变）
有滑音：C4 end=1.0, C#4 start=1.0, D4 start=1.03, D#4 start=1.06, E4 start=1.1
（在跳进之间加入经过音，模拟滑音）
```

滑音时每个中间音的力度应该很低（30–40），因为它们只是过渡。

## 四、音符时值的自然处理

### 问题：时值太"方"

AI 给出的音符时值往往是整齐的整数或 .25/.5/.75，像数学公式。

### 解决方案：自然的时值变化

1. **长音的衰减**：一个 2 拍的长音，实际发声可能只有 1.5 拍就自然衰减了
   - `start: "1", end: "2.8"`（而不是严格的 `end: "3"`）

2. **短音的"不够短"**：一个十六分音符实际时长可能比理论值略长
   - `start: "1", end: "1.14"`（而不是严格的 `end: "1.125"`）

3. **休止的不规则**：乐句的呼吸点可以不完全对齐网格
   - 下一次音符从 `2.03` 而不是 `2.0` 开始

4. **附点的灵活性**：附点音符的时值可以比理论值略长或略短
   - `start: "1", end: "1.8"`（附点四分，理论 0.75 拍，但加一点弹性）

### 参考微调量

| 时值类型 | 微调范围 | 方向 |
|---------|---------|------|
| 十六分音符 | ±0.01–0.02 | 任意 |
| 八分音符 | ±0.01–0.03 | 任意 |
| 四分音符 | ±0.02–0.05 | 略长更自然 |
| 二分/长音 | ±0.03–0.08 | 通常略短（衰减）|

## 五、不同风格的"人味"程度

| 风格 | 时间微调 | 力度变化 | 音符重叠 |
|------|---------|---------|---------|
| 古典 | 极小（±0.01） | 遵循乐谱标记 | 按乐谱要求 |
| 流行 | 小（±0.02） | 有起伏 | 旋律 legato |
| 摇滚 | 中等（±0.03） | 动态大 | 节奏感强，少重叠 |
| Jazz | 大（±0.03–0.06） | 变化丰富 | 大量重叠 |
| R&B | 大（±0.03–0.06） | 细腻变化 | 滑音 + 重叠 |
| EDM | 极小（几乎无） | 可以规律 | 无重叠（干净的 16 分） |
| Hip-hop | 大（±0.04–0.06） | 重低音突出 | 人声 legato |

## 六、润色清单

AI 在输出 note_table 后，应做以下润色检查：

| 检查项 | 问题 | 修正 |
|--------|------|------|
| 力度均匀 | 所有音符 vel 相同 | 按节拍位置和音高调整 |
| 时间死板 | 全部对齐到网格 | 加入 ±0.01–0.03 的偏移 |
| 音符有隙 | 相邻音符 end < 下一 start | 消除缝隙或加入 overlap |
| 长音不变 | 2 拍音从头强到尾 | 长音力度递减 |
| 和弦太齐 | 和弦内所有音力度一样 | 根音稍强，五音稍弱 |
| 转音太响 | 装饰音符力度和主音一样 | 装饰音 vel 降低 20–30 |
| 高音太冲 | 高音区音符力度过高 | 高音区 vel 降低 10–15 |
| 低音太弱 | 低音音符听不到 | 低音 vel 提高 10–15 |

---

## 七、实用润色规则（AI 应该自动遵循）

1. 旋律音符的 velocity 在 75–100 之间波动，按节拍强弱变化
2. 和弦/伴奏音符的 velocity 比同位置旋律低 15–25
3. 转音/装饰音的 velocity 比主旋律低 25–40
4. 级进连接的旋律音符之间保持 legato（start/end 时间相同或有轻微重叠）
5. 大跳（超过纯五度）的起始音可以略微提前（抢拍感）
6. 乐句的最后一个音可以略微延后（拖拍感，像叹息）
7. 连续相同的节奏型中，第 3、4 次重复的力度可以递增
8. 和弦变化点：新和弦的第一个音力度稍强，旧的最后一个音力度稍弱
