# 音阶与即兴创作参考

本文件为 AI 的创作类任务提供常用音阶模板和即兴素材，帮助生成符合风格的音乐内容。

---

## 一、常用音阶模板

以下列出各调式音阶的音级（以 C 为根音的变体），AI 可以根据调性自行移调。

### 自然大调（Ionian）

C D E F G A B C（全–全–半–全–全–全–半）

### 自然小调（Aeolian）

A B C D E F G A（全–半–全–全–半–全–全）

### 和声小调

A B C D E F G# A（自然小调 + 升 VII）

### 旋律小调（上行）

A B C D E F# G# A（升 VI、VII）

### 多利亚（Dorian，D 为根音）

D E F G A B C D（全–半–全–全–全–半–全）→ 小调 + 自然六度

### 弗里吉亚（Phrygian，E 为根音）

E F G A B C D E（半–全–全–全–半–全–全）→ 小调 + 小二度

### 利底亚（Lydian，F 为根音）

F G A B C D E F（全–全–全–半–全–全–半）→ 大调 + 升四度

### 混合利底亚（Mixolydian，G 为根音）

G A B C D E F G（全–全–半–全–全–半–全）→ 大调 + 小七度

### 洛克利亚（Locrian，B 为根音）

B C D E F G A B（半–全–全–半–全–全–全）→ 小调 + 减五度

### 五声音阶（以 C 为例）

C D E G A C（缺四级和七级，无半音冲突，任意组合都好听）

### 布鲁斯音阶（以 C 为例）

C Eb F F# G Bb C（加 blue note F#/Gb）

### 日本都节音阶（以 C 为例）

C Db F G Ab C（半–全–全–半–全–全）

### 西班牙弗里吉亚音阶（以 E 为例）

E F G# A B C D E（半音开头，小调色彩，弗拉门戈感）

### 匈牙利小调音阶（以 A 为例）

A B C D# E F G# A（升高四度的小调，东欧色彩）

| 音阶 | 可用和弦 |

| 自然大调 | I, ii, iii, IV, V, vi, vii° |
| 自然小调 | i, ii°, III, iv, v, VI, VII |
| 和声小调 | i, ii°, III+, iv, V, VI, vii° |
| 多利亚 | i, II, III, iv, v°, VI, VII |
| 弗里吉亚 | i, II, III, iv, v°, VI, vii° |
| 利底亚 | I, II, iii, #iv°, V, vi, vii° |
| 混合利底亚 | I, ii, iii°, IV, v, vi, vii° |

## 三、即兴创作模板

### 模板：一段 4 小节的旋律（4/4 拍，BPM 120）

```
小节 1：调内分解和弦上行（建立调性）
小节 2：音阶经过 + 一个小跳进
小节 3：动机重复（移高或移低）
小节 4：终止解决（级进到主音）
```

### 模板：填充段落（Fills）

在乐句之间的短过渡（1–2 拍）：

```
音符 1：从上一乐句最后一个音级进上行/下行
音符 2–3：快速经过音阶的 2–3 个音
音符 4：落在下一乐句第一个和弦音上
```

### 模板：重复段落的微变

- 第一次：原样重复
- 第二次：提高八度，或加入装饰音
- 第三次：改变节奏（原八分改十六分，或增加切分）
- 第四次：回归原版，形成"原–变–变–归"结构

## 五、MIDI 创作实用规则

在通过 note_table 创作新音符时：

1. **节奏型固定框架**：先确定整体节奏骨架（哪些位置有音），再填充音高
2. **音符时长规则**：
   - 旋律音符：0.25 – 2.0 拍
   - 和弦/伴奏音符：0.25 – 1.0 拍
   - 转音装饰音符：0.05 – 0.25 拍
3. **时间网格对齐**：所有 start/end 值尽量对齐到 0.25 拍（十六分音符）网格
4. **不重叠**：同一个音符名在同一时间不能出现两个（除非明确的多声部）
5. **力度渐变**：连续音符的 velocity 应该有起伏，不要全部相同
