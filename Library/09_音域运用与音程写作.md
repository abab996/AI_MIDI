# 音域运用与音程写作

本文件指导 AI 如何合理运用音域、设计音程跨度，写出有张力和空间感的旋律。

---

## 一、音域基本概念

### 音域（Range）

指一段旋律从最低音到最高音所覆盖的音高区间。**好听的旋律几乎从来不会局限在一个八度内。**

| 音域宽度 | 效果 | 适用场景 |
|---------|------|---------|
| 纯一度（不移动） | 单调、催眠 | 极少使用 |
| 一个八度内 | 平稳、收敛 | 主歌、桥段铺垫 |
| 一个半到两个八度 | 舒展、有展开空间 | 副歌、高潮 |
| 两个以上八度 | 宏大、戏剧性 | 咏叹调、史诗配乐 |

### 最佳音区（Tessitura）

旋律最频繁出现的音区，不一定是最低到最高的中间点，而是音乐最"舒服"的区域。

- 主歌的最佳音区：通常在中低区，方便叙事
- 副歌的最佳音区：通常在高区，制造高潮感
- 过门/桥段：可以刻意移到低区或高区制造对比

## 二、八度内音程布局

### 低音区（第一个八度的下半部分）

- 给人厚重、沉稳、内省的感觉
- 适合：主歌开头、情绪铺垫、对话感
- 避免：长期停留在极低音（低于 C3），会显得压抑

### 中音区（中央 C 附近，C3–C5）

- 最自然、最亲切的音区
- 适合：大多数旋律的主体部分
- 人类说话的频率范围大致在此区间

### 高音区（C5 以上）

- 给人明亮、突破、高潮的感觉
- 适合：副歌的最高点、情绪爆发
- 适度使用高音，如果全段都在高区会显得疲惫

### 音区分布原则

```
主歌：   ████████░░░░░░░░  （偏中低区）
预副歌： ░░░████████░░░░░░  （逐步上升）
副歌：   ░░░░░░████████░░░  （中高区，包含最高音）
桥段：   ████░░░░░░░░████  （对比：低区开头 → 冲向高区）
结尾：   ░░░░░░░░████░░░░░  （回归中区，有余韵）
```

## 三、音程写作规则

### 音程分级

| 音程 | 半音数 | 特征 |
|------|--------|------|
| 小二度 | 1 | 最紧张，制造冲突 |
| 大二度 | 2 | 柔和的不稳定 |
| 小三度 | 3 | 忧伤、柔和 |
| 大三度 | 4 | 明亮、温暖 |
| 纯四度 | 5 | 开放、空旷 |
| 增四/减五 | 6 | 极不稳定，需要解决 |
| 纯五度 | 7 | 和谐、有力 |
| 小六度 | 8 | 深情、辽阔 |
| 大六度 | 9 | 明亮但不过分 |
| 小七度 | 10 | 蓝调感、不完美 |
| 大七度 | 11 | 梦幻、需要解决 |
| 纯八度 | 12 | 宏大、稳定 |

### 大跳的使用原则

1. **大跳后级进回归**：跳超过五度的音程后，下一音应该反向级进，不要连续大跳
   - ✅ C4 → G4（纯五度跳）→ F4 → E4（级进回归）
   - ❌ C4 → G4 → C5 → G4（连续大跳，粗糙）

2. **强拍用大跳**：弱拍可以小跳，强拍用大跳能制造亮点
   - 弱拍：级进为主
   - 强拍：大跳制造惊喜

3. **上行大跳要小于下行大跳**：上行大跳超过八度会很吃力
   - 上行大跳建议不超过纯八度
   - 下行大跳可以更自由

4. **重复音之间的跳跃**：如果旋律在同一个音上停留，下一次出现时移动大跳
   - C4（停）→ E4（大三度跳）比 C4 → C#4（小二度）更有表现力

### 连续音程变化模板

```
模式 A（级进为主）：
C4 → D4 → E4 → F4 → E4 → D4 → C4
（平滑、自然，像说话）

模式 B（跳进+级进）：
C4 → E4 → F4 → G4 → F4 → E4 → C4
（有起伏，更好听）

模式 C（大幅跳跃）：
C3 → G3 → C4 → E4 → C4 → G3 → C3
（两个八度内的大弧线，有戏剧性）
```

## 四、避免音域陷阱

### 陷阱 1：挤在一个八度内

```
❌ 差：C4 D4 E4 F4 G4 A4 B4 C5（全程 C4–C5，单调）
✅ 好：G3 → C4 → E4 → G4 → C5（跨两个八度，有空间）
```

### 陷阱 2：上下扫来扫去

```
❌ 差：C5 → G3 → C5 → G3 → C5 → G3（超过两个八度来回跳，头晕）
✅ 好：G3 → C4 → E4 → G4 → C5 → G4 → E4 → C4（大弧线，有方向感）
```

### 陷阱 3：高音滥用

```
❌ 差：每个乐句的最高音都在 C5–C6 区间（疲劳）
✅ 好：只在副歌最高点冲上高音区，其他时候保持在舒适区
```

### 陷阱 4：低音不足

```
❌ 差：旋律全程 C4–G4，中音区，没有深度
✅ 好：主歌从 G3 开始，逐步上升到副歌的 C5
```

## 五、旋律音域设计模板

### 模板 A：经典上升弧线

```
起点（主歌）：中低区，如 G3–B3
过渡（预副歌）：逐步上升，C4–E4
高点（副歌第一拍）：冲高到 G4–C5
回落（副歌后半）：E4–G4，不完全回落
终点：C4 或 G4，留有余韵
```

### 模板 B：拱形旋律

```
起点：中低区
逐步上升到高点（在中段）
再逐步回落
起点和终点在同一音区（对称感）
```

### 模板 C：阶梯上升

```
乐句 1：G3–C4（第一级）
乐句 2：C4–E4–G4（第二级）
乐句 3：G4–B4–C5（第三级）
乐句 4：回落解决到 C4
```
每段乐句整体上升，最后回落，制造层层推进的感觉。

### 模板 D：低音铺垫 → 高音爆发

```
主歌（低区）：C3–G3，叙事感，低沉
预副歌（上升）：C4–E4，能量积聚
副歌（高区爆发）：G4–C5–E5，释放
桥段（低区对比）：G3–C4，突然安静
最后副歌（更高）：C5–E5–G5，最高点
```

## 六、和弦音与经过音的平衡

### 和弦音（Chord Tones）

- 旋律音落在和弦的根音、三音、五音上
- 感觉"稳定"、"到位"
- 强拍位置应该尽量用和弦音

### 经过音（Passing Tones）

- 在两个和弦音之间级进经过的音
- 感觉"流动"、"过渡"
- 弱拍或半拍位置使用

### 平衡原则

```
好的旋律 = 约 60% 和弦音 + 40% 经过音
全和弦音 → 呆板、像视唱
全经过音 → 没有骨架、找不到调
```

在 note_table 中：
- 落在强拍上的音符优先用和弦音
- 弱拍或八分/十六分音符可以大胆使用经过音
- 乐句的起点和终点应该用和弦音
