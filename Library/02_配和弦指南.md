本文件为 AI 配和弦功能提供专业知识指导。

## 一、和弦构成

### 三和弦

| 名称 | 结构 | 示例（C 为根音） |
|------|------|-----------------|
| 大三和弦 | 大三度 + 小三度 | C–E–G |
| 小三和弦 | 小三度 + 大三度 | C–Eb–G |
| 增三和弦 | 大三度 + 大三度 | C–E–G# |
| 减三和弦 | 小三度 + 小三度 | C–Eb–Gb |

## 三、和弦进行规律

### 经典进行

- I–V–vi–IV（流行四和弦）
- I–vi–IV–V（50年代进行）
- ii–V–I（爵士最基础进行）
- I–IV–V–I（古典基础进行）
- vi–IV–I–V（抒情进行）
- I–V–vi–iii–IV–I–IV–V（八和弦循环）

### 和弦连接规则

1. **就近原则**：和弦根音优先以级进方式连接，跳进不超过四度以上尽量避免连续使用
2. **共同音保持**：相邻和弦尽量保留 1–2 个共同音，减少声部跳跃
3. **避免平行五度/八度**：两个声部同时以纯五度或纯八度同向移动是禁止的
4. **声部平滑**：内声部尽量保持平稳，避免不必要的跳跃
5. **低音线条**：低音（贝斯线）可以更自由地跳进，创造律动感

### 功能性逻辑

- **T（主功能）**：I、vi、iii — 稳定、归家感
- **S（下属功能）**：IV、ii — 推动、准备
- **D（属功能）**：V、vii° — 张力、需要解决
- 功能走向：T → S → D → T（最自然）
- 避免直接 S → D（例外：IV → V 可接受）

## 四、和弦选择策略（配和弦时使用）

### 根据旋律音选择和弦

1. 优先让旋律音落在和弦音（根音、三音、五音）上
2. 强拍位置优先使用和弦音
3. 弱拍/经过音可以使用非和弦音
4. 非和弦音类型：
   - 经过音（在两个和弦音之间级进）
   - 辅助音（围绕一个和弦音的上下二度交替）
   - 延留音（前一和弦音延续到下一拍）
   - 先现音（后一和弦音提前出现）

### 节奏匹配

- 旋律节奏越快，和弦变化应越少（避免过于密集）
- 旋律节奏越慢，可以适当增加和弦变化频率
- 通常每 1–4 拍换一个和弦
- 长音/休止符是换和弦的好时机

### BPM 参考

- < 60 BPM：每 2–4 小节换和弦
- 60–100 BPM：每 1–2 小节换和弦
- 100–140 BPM：每 1 小节或每半小节换和弦
- > 140 BPM：每 2–4 小节换和弦（快反而少换）

### 情绪参考

- 明亮/欢快：多用大三和弦，I–IV–V 进行
- 忧郁/深沉：引入小调和弦，vi–IV–ii–V
- 紧张/戏剧性：加入减和弦和属七，vii°–I
- 梦幻/飘渺：使用大七和弦、挂留和弦（sus2/sus4）
- 爵士感：加入九和弦、十三和弦，使用 ii–V–I

## 五、输出要求

配和弦时，AI 需要在 note_table 中补充和弦音符的条目。具体要求：

1. 保留原始旋律音符不变
2. 在和弦变化点插入和弦音符（可放在同一 start 时间）
3. 和弦音符的 velocity 通常低于旋律音符（60–80 vs 旋律 80–100）
4. 和弦音符的 end 时间通常比旋律短（1/4–1/2 拍即可，体现"弹一下"的感觉）
5. 注意声部间距：和弦各音之间尽量保持在合理音程内（不跨越太宽）
6. 最终输出必须只包含 note_table 格式，无额外文字
