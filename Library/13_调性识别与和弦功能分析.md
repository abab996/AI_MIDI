# 调性识别与和弦功能分析

本文件指导 AI 如何从一段旋律中识别调式/调号，并据此做出正确的和弦选择。这是配和弦功能的前置核心步骤。

---

## 一、为什么调性识别至关重要

配和弦的第一步永远是**确定调式**。如果调式判断错误，后续所有和弦选择都会偏离。

常见的调性判断失误：
- 将自然小调当作关系大调（如把 Am 当成 C 大调）
- 忽略了和声小调的升 VII 级
- 未识别到调式借用和弦导致的调性模糊

---

## 二、调性识别步骤

### 步骤 1：找出旋律的结束音

旋律的最后一个音或最后一个和弦音几乎总是落在主音上。

```
旋律结束于 C → 可能是 C 大调或 a 小调
旋律结束于 D → 可能是 D 大调或 b 小调
旋律结束于 E → 可能是 E 大调或 #c 小调（较少见）
```

### 步骤 2：看结束和弦的感觉

- 结束在大三和弦 → 大调
- 结束在小三和弦 → 小调
- 结束在属和弦（V）上 → 半终止（乐句未完）
- 结束在减和弦 → 通常是小调的 vii°

### 步骤 3：检查特征音

| 特征音 | 指向的调式 |
|--------|-----------|
| 旋律中有 B♮ 且结束于 C | C 大调 |
| 旋律中有 B♮ 且结束于 Am | a 自然小调（VII 是 G）|
| 旋律中有 G# 且结束于 Am | a 和声小调（升 VII）|
| 旋律中有 F# 且结束于 D | D 大调 |
| 旋律中有 C# 且结束于 E | E 大调（4 个升号）|
| 旋律中有 Bb 且结束于 C | C 大调（F 大调关系调）或 C Mixolydian |
| 旋律中有 Bb 且结束于 F | F 大调 |

### 步骤 4：确认调号

| 调号 | 大调 | 小调（关系调） | 升号数 | 降号数 |
|------|------|-------------|--------|--------|
| C | C 大调 | a 小调 | 0 | 0 |
| G | G 大调 | e 小调 | 1(F#) | 0 |
| D | D 大调 | b 小调 | 2(F#,C#) | 0 |
| F | F 大调 | d 小调 | 0 | 1(Bb) |
| Bb | Bb 大调 | g 小调 | 0 | 2(Bb,Eb) |
| Eb | Eb 大调 | c 小调 | 0 | 3(Bb,Eb,Ab) |

### 步骤 5：验证

用调内的音阶音验证旋律中的每个音是否都在调内。如果有少数音不在调内，它们可能是：
- 调式借用和弦的音
- 经过音/辅助音（不构成和弦）
- 蓝调音（blues note）
- 装饰音

## 三、各调式的调内和弦速查

### C 大调调内和弦

```
I      = C      (C–E–G)
ii     = Dm     (D–F–A)
iii    = Em     (E–G–B)
IV     = F      (F–A–C)
V      = G      (G–B–D)
vi     = Am     (A–C–E)
vii°   = Bdim   (B–D–F)
```

### a 自然小调调内和弦

```
i      = Am     (A–C–E)
ii°    = Bdim   (B–D–F)
III    = C      (C–E–G)
iv     = Dm     (D–F–A)
v      = Em     (E–G–B)
VI     = F      (F–A–C)
VII    = G      (G–B–D)
```

### a 和声小调调内和弦

```
i      = Am     (A–C–E)
ii°    = Bdim   (B–D–F)
III+   = Caug   (C–E–G#)  ← 增三和弦（升 III 级）
iv     = Dm     (D–F–A)
V      = E      (E–G#–B)   ← 大三和弦（升 VII 级，导音）
VI     = F      (F–A–C)
vii°   = G#dim  (G#–B–D)  ← 注意 G# 而非 G
```

### G 大调调内和弦

```
I      = G
ii     = Am
iii    = Bm
IV     = C
V      = D
vi     = Em
vii°   = F#dim
```

### F 大调调内和弦

```
I      = F
ii     = Gm
iii    = Am
IV     = Bb
V      = C
vi     = Dm
vii°   = Edim
```

### D 小调调内和弦

```
i      = Dm
ii°    = Edim
III    = F
iv     = Gm
v      = Am（自然）/ A（和声）
VI     = Bb
VII    = C（自然）/ C#（和声）
```

## 四、调性判断中的常见难点

### 难点 1：C 大调 vs a 小调

两者的音完全一样（关系大小调），只能通过上下文判断：

```
线索 1：结束音落在 C 而非 Am → 大调
线索 2：旋律中 G# 出现 → 小调（导音升高）
线索 3：和弦进行以 Am 开始 → 可能小调
线索 4：旋律情感色彩偏忧伤 → 小调
线索 5：多次出现 E（小调的 III 级）而非 Eb → 自然小调
```

### 难点 2：Mixolydian（混合利底亚）

大调 + 降 VII 级。特征：有大调的明亮感，但结尾有一点不完美的 bluesy 感觉。

```
C Mixolydian：C D E F G A Bb
特征音：Bb（大调中没有这个音）
典型使用：摇滚、Funk、乡村
```

### 难点 3：Dorian（多利亚）

小调 + 升 VI 级。特征：小调的忧郁 + 大六度的温暖。

```
D Dorian：D E F G A B C
特征音：B（自然小调中是 Bb）
典型使用：民谣、凯尔特、爵士
```

### 难点 4：调式模糊（Modal Mixture）

一段旋律可能同时包含多个调式的特征音，这时需要：
1. 确定"家"（主要调式）
2. 将其他调式的音标记为"借用"
3. 选择和弦时优先使用主调式，借用和弦作为色彩点缀

## 五、给配和弦的具体指令

当 AI 需要为一组旋律音符配和弦时，应按以下流程思考：

```
第 1 步：观察旋律中所有出现过的音
第 2 步：找出结束音（大概率是主音）
第 3 步：以结束音为根音，尝试大调和小调两种可能性
第 4 步：检查旋律中是否有特征音（升 VII → 和声小调，降 VII → Mixolydian 等）
第 5 步：确定调式和调号
第 6 步：从该调式的调内和弦中选择
第 7 步：必要时使用借用和弦增加色彩
第 8 步：按 BPM 和情绪调整和弦变化频率
```

### 快速判断示例

```
旋律结束于 E，旋律中有 D#：
→ e 小调（和声小调，升 VII 级 D#）
→ 调内和弦：Em – F#dim – G – Am – Bm – C – D#dim

旋律结束于 G，旋律中有 F#：
→ G 大调
→ 调内和弦：G – Am – Bm – C – D – Em – F#dim

旋律结束于 A，旋律中有 G 和 G# 交替：
→ a 小调（旋律小调或调式混合）
→ 以 Am 为主，G# 出现时用 E 大三和弦（属和弦）
```

## 六、调号与 note_table 的关系

当 AI 读取 note_table 中的旋律时：

1. **收集所有音名**：从 `[note: "..."]` 中提取所有音名
2. **统计出现频率**：出现最多的音可能是主音或属音
3. **寻找特征音**：是否有升 VII 或降 VII 等特征音
4. **看结束音**：最后一个音符的音名
5. **综合判断**：频率 + 特征音 + 结束音 = 最可能的调式

在配和弦的输出中，AI 不需要显式声明调式，但需要在选择和弦时**内部使用正确的调式逻辑**。
