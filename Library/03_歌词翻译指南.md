# 歌词翻译与贴合旋律

本文件为 AI 翻译歌词功能提供专业指导，确保翻译结果在语义、音节数和节奏上都能与原曲旋律完美贴合。

---

## 一、音节匹配原则

### 一对一匹配

- 每个源语言音节应对应一个目标语言音节
- 如果源语言有 N 个音节，翻译后也应恰好有 N 个音节
- 这是与旋律贴合的最基本要求

### 处理音节数量差异

| 情况 | 策略 |
|------|------|
| 目标语言音节 > 源语言 | 合并短音节（如法语 "au"→"哦"）、使用复合词 |
| 目标语言音节 < 源语言 | 省略非重读音节、使用缩略表达、多音节词合并 |
| 目标语言音节 ≪ 源语言 | 考虑添加衬词（啦、啊、哟），或拆分旋律时值 |

---

## 二、重音与节奏对齐

### 中文歌词重音

- 中文以字为单位，每个字自然带一个重音
- 注意四声调：第一声（平）、第二声（升）、第三声（拐）、第四声（降）
- 旋律走向与声调走向协调会更自然：
  - 上行旋律 + 升调（第二声）→ 自然
  - 下行旋律 + 降调（第四声）→ 自然
  - 避免上行旋律配降调、下行旋律配升调（除非刻意为之）

### 英语歌词重音

- 英语有重读音节和弱读音节之分
- 重读音节对应强拍/长音
- 弱读音节对应弱拍/短音
- 注意单词中自然重音的位置

### 日语歌词

- 每个假名 = 一个音节（平假名或片假名）
- 长音「—」占一拍
- 促音「っ」占一拍但不发音
- 拨音「ん」占一拍
- 输出翻译歌词时，后面必须列出对应的平假名

---

## 三、常见语言音节特征

| 语言 | 音节特征 |
|------|---------|
| 中文 | 一字一音节，声调丰富，无尾音 |
| 日语 | 假名一字一音节，有长音/促音/拨音 |
| 英语 | 单词有重音/弱读之分，尾音常见（-tion, -ing） |
| 法语 | 尾音多（-tion, -ment），联诵现象 |
| 韩语 | 音拍（자음+모음 或 받침），结构固定 |

---

## 四、意译与直译的平衡

### 何时直译

- 专有名词（人名、地名）
- 常用习语对应明确时
- 叙事性歌词中需要保持情节准确

### 何时意译

- 修辞手法（比喻、拟人、夸张）
- 文化特定表达
- 押韵需求导致需要调整时
- 为了音节匹配不得不调整时

### 译歌注意事项

1. **押韵**：在目标语言的押韵习惯下尽量押韵
2. **意境**：保持原曲情感色彩不变
3. **口型**：元音开口度与旋律线条的起伏协调
4. **难唱音**：如果某个音高对应一个难发的辅音，考虑替换同义词

---

## 五、输出要求

翻译歌词任务中，AI 的输出应该是**纯翻译后的歌词文本**，不包含 note_table 格式数据。

输出格式：
1. 先输出翻译后的歌词原文
2. 如果目标语言是日语，在翻译歌词后面列出其对应的平假名
3. 每行歌词对应原旋律的一个乐句
4. 保持换行位置与原歌词大致对应

**禁止**在翻译结果中掺杂 note_table 格式或其他无关内容。
