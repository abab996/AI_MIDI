# 转音与装饰音写作

本文件为 AI 设计转音（melisma / 花腔 / 装饰音）功能提供专业知识指导。

---

## 一、转音类型

### 1. 滑音（Glissando / Portamento）

- 在两个音符之间连续滑过所有中间音
- 适合表现情感强烈的过渡
- 在 note_table 中以密集的音符序列模拟

### 2. 倚音（Appoggiatura / Grace Note）

- 在主音之前快速带过的音符
- 上倚音：比主音高二度
- 下倚音：比主音低二度
- 时值极短（通常为原时值的 1/4 或更短）

### 3. 颤音（Trill）

- 在相邻两个音之间快速交替
- 通常从上方音开始
- 持续 1–2 拍或更长
- 在 note_table 中以极短时值的交替音符序列表示

### 4. 回音（Turn）

- 围绕主音的装饰：上方音→主音→下方音→主音
- 增加音乐的精致感和流动感

### 5. 经过音群（Passage / Run）

- 快速级进的一组音符（五声音阶或音阶片段）
- 通常 4–8 个音符
- 时值极短，创造炫技效果

### 6. 花腔（Coloratura）

- 复杂的装饰音组合
- 常见于声乐中，在高音区发挥
- 包含大跳、快速音阶、颤音等多种技巧

---

## 二、转音写作原则

### 音域安全

- 转音不得超出原旋律的合理音域太多（建议 ±5 个半音以内）
- 避免突兀的大跳（超过纯五度）出现在转音内部
- 转音结束必须回到原旋律音

### 节奏适配

- 转音的密度应与 BPM 匹配：
  - 慢速（<80 BPM）：可以更慢、更清晰的转音
  - 中速（80–120 BPM）：中等密度
  - 快速（>120 BPM）：更密集的音符
- 每个转音音符的时值通常为原音符的 1/8–1/4

### 情感匹配

| 情感 | 推荐转音风格 |
|------|-------------|
| 悲伤 | 下滑音、小二度倚音、半音经过音 |
| 欢快 | 五声音阶快速级进、大三度跳进 |
| 激情 | 大跳 + 回弹、长颤音 |
| 温柔 | 轻柔的倚音、微小的滑音 |
| 戏剧性 | 大幅度跳进后快速回归、花腔 |

### 避免过度

- 转音太多会让旋律变得嘈杂
- 通常只在乐句的重点音上添加转音
- 长音（超过 1 拍）最适合加转音
- 短音（四分音符以下）一般不加转音

## 三、五声音阶转音模板

五声音阶（C D E G A）是最安全的转音素材，在任何调式中都能使用：

```
C: C D E G A C(高八度) G E D C
D: D E G A C D(高) A G E D
E: E G A C D E(高) C A G E
G: G A C D E G(高) E D C A G
A: A C D E G A(高) G E D C A
```

转音设计时，可以根据原旋律的调式选择对应的五声音阶变体。

---

## 四、输出要求

设计转音时，AI 的输出必须只包含 note_table 格式的音符数据：

1. 保留原始旋律音符不变
2. 在需要添加转音的位置，在原始音符之间插入装饰音符
3. 装饰音符的 start/end 时间必须精确，与前后音符无缝衔接
4. 装饰音符的 velocity 通常低于旋律音符（40–60）
5. 注意转音音符之间不能有时隙（时间必须连续）
6. 转音结束音必须与下一个原始旋律音的 start 时间完全对齐

## 五、常见转音模式示例

### 长音上的颤音转音（以 C4 持续 2 拍为例）

```
[note: "C4", velocity: "80", start: "1", end: "3"]
```

转音后可能变为：

```
[note: "C4", velocity: "70", start: "1", end: "1.125"]
[note: "D4", velocity: "50", start: "1.125", end: "1.25"]
[note: "C4", velocity: "50", start: "1.25", end: "1.375"]
[note: "D4", velocity: "50", start: "1.375", end: "1.5"]
[note: "C4", velocity: "50", start: "1.5", end: "1.625"]
[note: "D4", velocity: "50", start: "1.625", end: "1.75"]
[note: "C4", velocity: "70", start: "1.75", end: "3"]
```

### 两音之间的滑音转音（从 C4 到 E4，1 拍）

```
[note: "C4", velocity: "80", start: "1", end: "2"]
[note: "E4", velocity: "80", start: "2", end: "3"]
```

转音后可能变为：

```
[note: "C4", velocity: "80", start: "1", end: "2"]
[note: "C#4", velocity: "45", start: "2", end: "2.125"]
[note: "D4", velocity: "45", start: "2.125", end: "2.25"]
[note: "D#4", velocity: "45", start: "2.25", end: "2.375"]
[note: "E4", velocity: "80", start: "2.375", end: "3"]
```
