# 风格化写作与编曲要素

本文件为 AI 提供不同音乐风格的写作特征和编曲要素，帮助在不同风格下生成恰当的旋律、和弦和节奏。

---

## 一、流行 Pop

### 核心特征

- 旋律：好记，音域一个半八度，以三度内级进为主
- 和弦：常用 I–V–vi–IV，偶尔加入 sus 和弦
- 节奏：四四拍，强弱规律，反拍重音
- 织体：主旋律 + 分解和弦伴奏

### 段落特征

| 段落 | 音区 | 节奏 | 和弦密度 |
|------|------|------|---------|
| Intro | 低–中 | 疏 | 慢 |
| Verse | 中低 | 中等 | 中等 |
| Pre-chorus | 中 | 逐渐密 | 加速 |
| Chorus | 中高 | 密 | 快 |
| Bridge | 低–高 | 疏到密 | 变化 |
| Outro | 中 | 逐渐疏 | 慢 |

### Pop 旋律模板

```
主歌（8 小节）：
G3 → C4 → E4 → G4（级进上行，2 小节一组）
重复 2 次，第二次结尾略升

预副歌（4 小节）：
C4 → E4 → G4 → B4（上升推进）

副歌（8 小节）：
C5（长音）→ G4 → E4 → C4 → D4 → E4 → G4 → C5
（最高音 C5 放在第一拍，然后下降再上升回到 C5）
```

## 二、摇滚 Rock

### 核心特征

- 旋律：有力，有棱角，大跳更多
- 和弦：强力和弦（大三/小三 + 纯五度 + 八度），加入 bVII
- 节奏：切分多，反拍重，底鼓在 1、3，军鼓在 2、4
- 织体：失真吉他 riff + 贝斯线 + 鼓

### 摇滚 riff 特征

```
经典摇滚 riff 模式：
- 重复的短动机（2–4 个音）
- 以纯五度跳进为核心
- 加入小二度制造紧张
- 节奏型简洁但有力
```

### 摇滚和弦特征

```
强力和弦（Power Chord）：
根音 + 纯五度 + 根音高八度
没有三音，所以既不大三也不小三
可以放在任何调式中使用

示例：C5 = C2 + G2 + C3（吉他实际按法不同，但 MIDI 中是 C2/G2/C3）
```

## 三、R&B / Soul

### 核心特征

- 旋律：灵活，大量转音，蓝调音阶
- 和弦：七和弦、九和弦为主，色彩丰富
- 节奏：切分密集，三连音花腔，Groove 感极强
- 织体：和弦分解 + 转音旋律 + 贝斯 groove

### R&B 转音类型

```
1. 蓝调转音：3 → 3# → 3（小三度上的微滑动）
2. 滑音：5 → 4 → 5（上下摇摆）
3. 快速经过音：3 → 4 → 5 → 4 → 3（五声音阶跑动）
4. 颤音：在长音上快速 5↔3 交替
5. 三连音装饰：在 1 拍内完成 3 个快速音
```

### R&B 节奏特征

```
基本律动：每个八分音符分组为 3 个三连音
踩镲：密集的十六分音符或三连音
底鼓：在第 1 拍和第 3 拍偏后位置
军鼓：在第 2 拍和第 4 拍偏后位置
贝斯：反拍进，制造推拉感
```

## 四、爵士 Jazz

### 核心特征

- 旋律：以和弦音为主，蓝调音阶 + 调式音阶
- 和弦：九和弦、十三和弦、减七和弦，大量延伸音
- 节奏：摇摆八分音符（不平均），切分丰富
- 织体： Walking Bass + 和弦节奏吉他/钢琴 + 旋律

### 爵士和弦色彩

```
标准爵士和弦序列：
Cmaj7 → Dm7 → Em7 → Fmaj7 → G7 → Am7b5 → Bm7b5 → Cmaj7

每个和弦都用七和弦：
- 大三和弦 → 大七和弦（maj7）
- 小三和弦 → 小七和弦（m7）
- 属和弦 → 属七和弦（7）
- 减和弦 → 半减七和弦（m7b5）
```

### 爵士节奏（摇摆）

```
传统摇摆（Swing）：
八分音符不是平均的，而是三连音中的第 1 和第 3 个
1 & 2 & 3 & 4 &  在摇摆中变成：
1   &   2   &   3   &   4   &
（每个 & 的位置实际偏后）

现代爵士（后波普）：
八分音符偏平均，但保留切分
```

### 爵士旋律手法

```
1. 节奏变化：同一个旋律动机，在不同乐句中改变节奏
2. 即兴感：在框架内加装饰音、倚音、滑音
3. 蓝调音：加入 blue note（小三度的降五度）
4. 和弦音强调：在每个和弦变化时强调和弦音
```

## 五、古典 Classical

### 核心特征

- 旋律：音阶式级进为主，大跳少而精
- 和弦：功能和声，严格的声部连接规则
- 节奏：规整，但有小节内的节奏变化
- 织体：四部和声为主

### 古典乐句特征

```
对称乐句：
| 动机 A | 动机 A' | → 第一乐句（4 小节）
| 动机 B | 动机 B' | → 第二乐句（4 小节）

动机 A 和 A' 的关系：
- A' 通常是 A 的模进或变奏
- 有呼应感但又不完全重复
```

### 古典终止式

```
半终止：乐句在属和弦上结束 → V（未完待续）
全终止：乐句在主和弦上结束 → V – I（完成感）
阻碍终止：乐句在 vi 和弦上结束 → V – vi（意外转折）
```

## 六、电子 Electronic

### 核心特征

- 旋律：可以是极简的 loop，也可以是复杂的 lead
- 和弦：简单进行（1–4 个和弦循环），多用 sus 和弦
- 节奏：规律的鼓点，4/4 拍底鼓
- 织体：分层（pad + lead + bass + percussion）

### 各子流派特征

#### House

```
BPM：120–130
鼓点：四四拍底鼓 + 踩镲在反拍
和弦：简单的 I–IV–V 循环
织体：和声 pad + 旋律 lead + 低音 bass
```

#### Trance

```
BPM：130–150
鼓点：四四拍 + 踩镲十六分音符
和弦：长音 pad，缓慢变化
旋律：在 build-up 中逐步上升，drop 处爆发
织体：pad 铺底 → 逐步加入元素 → 爆发 → 回落
```

#### Dubstep / Bass Music

```
BPM：140–150（一半时值感觉像 70–75）
鼓点：底鼓 + snare 在反拍 +  halftime 感
特征：wobble bass（LFO 调制滤波）
旋律：在中高区，锯齿波感的 lead
织体：稀疏但每层都很有力量
```

#### Ambient / Drone

```
BPM：无明确节拍或极慢
特征：长音 pad，缓慢的和弦变化
旋律：极简，甚至没有明确旋律
织体：多层 pad 叠加 + 环境音效
```

## 七、中国风

### 核心特征

- 旋律：五声音阶为主，加入偏音增加色彩
- 和弦：宫–商–角–徵–羽 五声音阶内和弦
- 节奏：偏自由，有 rubato 感，不严格卡拍
- 织体：古筝分解 + 箫/笛旋律 + 琵琶/古琴装饰

### 五声音阶与和弦

```
五声音阶：宫 C 商 D 角 E 徵 G 羽 A
（没有四级 F 和七级 B）

五声音阶内和弦：
I（宫）= C–E–G（大三）
ii（商）= Dm（D–F–A，但 F 不在五声音阶内）
IV（徵）= G（G–B–D，B 不在五声音阶内）

所以中国风和弦要变通：
常用 I – vi – ii – V（C – Am – Dm – G）
加入偏音：bVII（清乐）、#IV（燕乐）
```

### 中国风旋律特征

```
1. 以五声音阶为主（C D E G A）
2. 加入偏音制造色彩：#F（变徵）、Bb（清角）
3. 装饰音：颤音、滑音、倚音（古筝/古琴技法模拟）
4. 节奏：偏自由，有散板感觉
5. 旋律线：起伏自然，像书法笔触
```

## 八、跨风格通用技巧

### 层次感（Layering）

一段好的编曲通常有多个层次：

```
底层：持续的低音/和弦 pad
中低层：节奏型（吉他/钢琴分解）
中层：主旋律
高层：装饰音/高音点缀
背景层：环境音/和声衬底
```

### 动态设计

| 段落 | 音量感 | 音域 | 节奏密度 |
|------|--------|------|---------|
| Intro | 弱 | 低–中 | 疏 |
| Build-up | 渐强 | 上升 | 渐密 |
| Drop/Chorus | 强 | 高 | 密 |
| Breakdown | 弱 | 低–中 | 疏 |
| Final chorus | 最强 | 全音域 | 密 + 加花 |

### 对比手法

- 快–慢：节奏密度的突然变化
- 响–静：音量/音符密度的突然变化
- 高–低：音区的突然变化
- 满–空：织体厚度的突然变化
- 这些对比是音乐"呼吸感"的来源
