# 旋律写作：如何写出好听的旋律

本文件聚焦旋律本身的美感设计，指导 AI 创作出有记忆点、有情感、好听的旋律线。

---

## 一、好旋律的核心要素

### 1. 记忆点（Hook）

一段旋律中最容易被记住的部分，通常是一个独特的音程或节奏组合。

- **位置**：通常在乐句的开头或高点
- **特征**：通常包含一个出人意料的音程（大跳或反向级进）
- **重复**：一个乐段中至少有一个 hook 被重复 2–3 次

```
记忆点示例：
"孤勇者"式 — 开头一个大跳：5 → 1（纯四度跳）
"小星星"式 — 级进 + 大跳回归：1 1 5 5 | 6 6 5 —
"卡农"式 — 琶音下行：3 2 1 7 6 5 1 5
```

### 2. 轮廓（Contour）

旋律的整体起伏形状，是听众在不记得具体音高时对旋律的印象。

| 轮廓类型 | 特征 | 情绪 |
|---------|------|------|
| 上升 | 整体从低到高 | 希望、上升、明亮 |
| 下降 | 整体从高到低 | 结束、回归、安详 |
| 拱形 | 先升后降 | 完整、对称、经典 |
| 波浪 | 上下起伏 | 流动、自然、口语化 |
| 阶梯 | 逐级上升 | 推进、急切、坚定 |

**设计原则**：一个乐句（4–8 小节）应有一个清晰的轮廓方向。

### 3. 节奏型（Rhythmic Identity）

旋律的节奏特征往往比音高更容易被记住。

- 等分节奏 → 机械感、军鼓感
- 切分节奏 → 律动感、摇摆
- 长短交替 → 歌唱感、语言感
- 突然休止 → 惊讶、停顿、呼吸

## 二、乐句设计

### 乐句长度

| 长度 | 特征 | 适用场景 |
|------|------|---------|
| 2 小节 | 短促、有力 | 说唱、号子、动机 |
| 4 小节 | 标准乐句 | 大多数流行歌 |
| 6 小节 | 略微不对称 | 需要一点意外的段落 |
| 8 小节 | 完整乐段 | 主歌/副歌标准长度 |
| 10+ 小节 | 展开、叙事 | 古典、叙事性歌曲 |

### 对称与不对称

- **对称**：4 + 4 小节，平衡、稳定
- **不对称**：3 + 3 小节，有轻微的不平衡感，更有趣
- **扩展**：4 + 6 小节，后半段多出 2 小节制造惊喜

### 乐句之间的呼吸

- 乐句之间必须有休止（至少 1 拍的沉默）
- 休止的位置通常在乐句的"语义终点"（如一个词的结尾）
- 没有呼吸的旋律会让人喘不过气

## 三、动机发展技巧

### 什么是动机（Motif）

一个 2–4 个音的简短音高–节奏组合，是整段旋律的"基因"。

```
好的动机示例：
"命运交响曲"：短–短–短–长（三个短音 + 一个长音）
"欢乐颂"：3 3 4 5 | 5 4 3 2（级进上下行）
"千本樱"：简化后是 5 5 6 5 3（跳进 + 回归）
```

### 动机发展手法

#### 1. 重复（Repetition）

直接重复动机，创造熟悉感。

```
动机：G4 – A4 – B4 – C5
重复：G4 – A4 – B4 – C5
```

#### 2. 模进（Sequence）

将动机在不同音高上重复，创造前进感。

```
原动机：C4 – D4 – E4 – F4
模进上行：D4 – E4 – F#4 – G4
模进下行：B3 – C4 – D4 – E4
```

#### 3. 变化重复（Variation）

重复动机但微调某个元素。

```
原动机：C4 – E4 – G4 – C5
变体 A（移高）：E4 – G4 – B4 – E5
变体 B（节奏变化）：C4 – (休) – E4 – G4 – C5
变体 C（音程变化）：C4 – F4 – G4 – C5（大三度变大二度）
```

#### 4. 倒影（Inversion）

动机的音程方向全部翻转。

```
原动机：C4 → E4 → G4 → A4（上行）
倒影：C4 → Ab3 → F3 → Eb3（下行，音程大小不变但方向反转）
```

#### 5. 逆行（Retrograde）

动机的音高顺序反过来。

```
原动机：C4 – E4 – G4 – C5
逆行：C5 – G4 – E4 – C4
```

#### 6. 截取（Fragmentation）

从动机中取一部分，只重复这一部分。

```
动机：C4 – D4 – E4 – F4 – G4
截取：E4 – F4 – G4（只取后半部分重复）
```

## 四、旋律线条的美学原则

### 原则 1：先跳后级

大跳之后紧接着级进回归，是最优美的组合。

```
✅ C4 → G4（纯五度跳）→ F4 → E4 → D4 → C4
❌ C4 → G4 → C5 → G4（连续大跳）
```

### 原则 2：长短交替

连续等长的音符会显得机械，长短交替创造语言感。

```
✅ C4（1拍）E4（0.5拍）G4（1拍）C5（0.5拍）G4（2拍）
❌ C4（0.5拍）E4（0.5拍）G4（0.5拍）C5（0.5拍）G4（0.5拍）
```

### 原则 3：弱起

从弱拍开始一个乐句（切分感），比从强拍开始更有动感。

```
✅ 从弱拍开始：_ _ C4 E4 G4 _ _（在第二拍后半拍起）
✅ 从强拍开始：C4 E4 G4 _ _ _ _（第一拍起）
```

### 原则 4：留白

不是每个位置都需要音符。适当的休止创造期待和呼吸感。

```
✅ C4 _ E4 _ G4 C5 _ _ _（有停顿，有期待）
❌ C4 E4 G4 C5 E4 G4 C5 E4（没有停顿，太满）
```

### 原则 5：高潮设计

一段旋律需要一个最高点（ Climax）。

- 高潮通常在乐段的 60–70% 位置（不是开头也不是结尾）
- 高潮通常是一个长音（时值较长）+ 高音 + 重力度
- 高潮之后应该回落，制造"释放感"

### 原则 6：重复与对比

- A 段：主题呈现
- A' 段：主题变化（微调节奏或移高八度）
- B 段：对比段落（不同的音区、节奏、情绪）
- A'' 段：回归主题，更强烈

## 五、不同风格的旋律特征

### 流行旋律

- 音域：一个半八度
- 节奏：以四分和八分音符为主，偶尔十六分
- 特征：记忆点强，重复度高，容易跟唱
- 音程：以二、三度级进为主，偶尔四、五度跳进

### 摇滚旋律

- 音域：一个到两个八度
- 节奏：切分多，有力量感
- 特征：大跳更频繁，更有攻击性
- 音程：三度、四度、五度跳进常见

### R&B 旋律

- 音域：一个半到两个八度
- 节奏：三连音、十六分花腔、切分
- 特征：大量转音、滑音、即兴感
- 音程：灵活，善用蓝调音阶

### 古典旋律

- 音域：两个八度或以上
- 节奏：规整但丰富
- 特征：对称、发展手法丰富
- 音程：音阶式级进为主，大跳少且精

### 民谣旋律

- 音域：一个八度左右
- 节奏：自由、口语化
- 特征：简单、重复、叙事性强
- 音程：级进为主，跨度小

### 电子旋律

- 音域：灵活
- 节奏：可以是简单的重复型，也可以是复杂的节奏型
- 特征： synth lead 常用锯齿波感的大跳旋律
- 音程：取决于子流派（house 较简单，dubstep 可很复杂）

## 六、常见旋律问题与修正

### 问题 1：音域太窄

```
❌ 症状：整个旋律都在 C4–G4 之间，没有起伏
✅ 修正：让副歌的最高音至少达到 C5，主歌可以从 G3 开始
```

### 问题 2：全是级进，没有亮点

```
❌ 症状：C D E F G A B C，像音阶练习
✅ 修正：在关键位置加入一个大跳（三度以上），如 C → E → F → G
```

### 问题 3：节奏太均匀

```
❌ 症状：全是四分音符，像节拍器
✅ 修正：长短交替，加入切分和休止
```

### 问题 4：没有高潮

```
❌ 症状：整段旋律力度和音高都在同一个水平线上
✅ 修正：在乐段的 2/3 处设计一个高点（高音 + 长音 + 重力度）
```

### 问题 5：乐句太长没有呼吸

```
❌ 症状：一个乐句 16 小节没有休止
✅ 修正：每 4–8 小节设置一个呼吸点
```
