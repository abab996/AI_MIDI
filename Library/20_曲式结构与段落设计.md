# 曲式结构与段落设计

本文件指导 AI 如何设计完整的音乐结构，让输出不只是零散的乐句，而是有完整起承转合的乐曲。

---

## 一、曲式基本概念

### 什么是曲式

曲式是音乐的组织方式——哪些段落出现、以什么顺序出现、各段落之间如何过渡。

### 基本单位

| 单位 | 长度 | 特征 |
|------|------|------|
| 动机（Motif） | 2–8 个音 | 最小的音乐细胞 |
| 乐汇（Phrase） | 2–4 小节 | 一个音乐"词" |
| 乐句（Sentence） | 4–8 小节 | 一个音乐"句子" |
| 乐段（Period） | 8–16 小节 | 一个音乐"段落" |
| 乐章（Movement） | 数百小节 | 一首曲子的一个部分 |

---

## 二、最常见的曲式

### AABA（32 小节曲式）

```
A段（8小节）：主题呈现
A段（8小节）：主题重复或微变
B段（8小节）：对比段落（Bridge/ Middle 8）
A段（8小节）：主题回归

总计：32 小节
适用：爵士标准曲、经典流行
```

### ABAB（主歌–副歌）

```
A段（主歌，8–16小节）：叙述、铺垫
B段（副歌，8小节）：高潮、核心信息
A段（主歌，8–16小节）：重复叙述
B段（副歌，8小节）：重复高潮
（可加入桥段、 outro 等扩展）

适用：绝大多数流行歌、摇滚
```

### Intro–Verse–Chorus–Verse–Chorus–Bridge–Chorus

```
Intro（4–8小节）：引入，建立调性和节奏
Verse 1（8–16小节）：主歌，叙述
Chorus 1（8小节）：副歌，第一次听到核心
Verse 2（8–16小节）：主歌，发展叙述
Chorus 2（8小节）：副歌，重复核心
Bridge（8小节）：桥段，转折或新视角
Chorus 3（8小节）：副歌，最强版本
Outro（4–8小节）：结尾，回归或收束

适用：现代流行歌、 ballad
```

### 12 小节布鲁斯

```
| I  | I  | I  | I  |
| IV | IV | I  | I  |
| V  | IV | I  | I  |

每小节 4 拍，共 12 小节
适用：蓝调、摇滚、R&B
```

### 奏鸣曲式（Sonata Form）

```
呈示部：
- 主题 A（主调）
- 过渡（连接部）
- 主题 B（关系调）

展开部：
- 主题的碎片化发展
- 调性游移

再现部：
- 主题 A 回归（主调）
- 过渡
- 主题 B 回归（主调）

适用：古典奏鸣曲、交响曲第一乐章
```

## 三、段落之间的对比与联系

### 对比手法

| 维度 | A 段 | B 段 | 效果 |
|------|------|------|------|
| 音区 | 中低区 | 中高区 | 空间对比 |
| 节奏 | 疏 | 密 | 密度对比 |
| 力度 | 弱 | 强 | 动态对比 |
| 织体 | 稀疏 | 丰富 | 厚度对比 |
| 调性 | 大调 | 小调 | 色彩对比 |
| 速度 | 慢 | 快 | 速度对比 |

### AABA 中 A 段之间的微变

```
A1（原版）：完整呈现主题
A2（变版）：微调节奏或移高八度
A3（回归版）：回归原版，但可以加一点装饰

三个 A 段的关系：相同但有微妙变化，既熟悉又有新鲜感
```

### 桥段（Bridge）的设计

桥段是整首歌的"转折点"，必须与前面的段落有明显不同：

```
桥段的特征：
1. 调性变化：转到关系调或平行调
2. 音区变化：移到之前没出现过的音区
3. 节奏变化：节奏型改变
4. 情绪变化：从平静到激动，或从激动到反思
5. 长度：通常比主歌短（4–8 小节）
6. 结尾：必须制造"回到副歌"的期待
```

桥段结尾通常：
- 在属和弦上（制造回到主和弦的期待）
- 在渐强中（制造能量上升）
- 用一个动机将桥段和副歌连接起来

## 四、段落设计的细节

### Intro（前奏）

| 类型 | 特征 | 适用场景 |
|------|------|---------|
| 氛围型 | 只有和弦长音，没有明确旋律 | 抒情、氛围音乐 |
| 动机型 | 重复一个短动机 | 流行、摇滚 |
| 上升型 | 逐步上升的音阶或琶音 | 电子、舞曲 |
| 引用型 | 用副歌旋律的片段 | 流行、民谣 |
| 鼓点型 | 只有鼓点，逐步加入乐器 | 摇滚、电子 |

### Verse（主歌）

- 功能：叙述、铺垫
- 旋律：中低音区，音域相对窄
- 节奏：相对简单，不抢副歌的风头
- 织体：相对稀疏
- 长度：8–16 小节
- 可以有两段（Verse 1、Verse 2），第二段旋律微变

### Pre-chorus（预副歌）

- 功能：过渡、制造张力
- 旋律：逐步上升，音量渐强
- 节奏：逐渐加密
- 织体：逐步加入元素
- 长度：4–8 小节
- 结尾：通常在属和弦上（V 或 V7），制造"即将爆发"的感觉

### Chorus（副歌）

- 功能：情感核心、记忆点
- 旋律：中高音区，音域最宽，包含最高音
- 节奏：最密、最有律动
- 织体：最丰富
- 长度：8 小节
- 重复 2–3 次，每次都稍强或稍丰富

### Bridge（桥段）

- 功能：转折、提供新视角
- 旋律：与前段不同，可能是低音区或更高音区
- 节奏：可以完全不同
- 织体：可以突然稀疏（创造"空"的感觉）或突然丰富
- 长度：4–8 小节
- 结尾必须引导回副歌

### Outro（结尾）

| 类型 | 处理方式 |
|------|---------|
| 渐弱型 | 乐器逐个退出，最后只剩一个音 |
| 回归型 | 回归 intro 的素材 |
| 延长型 | 副歌最后一个和弦延长 |
| 突然结束 | 最后一个音后直接静默 |
| 即兴型 | 最后一个段落即兴延长后结束 |

## 六、各段落的 note_table 设计要点

### 段落之间的音域过渡

```
段落 A（结束在 G4）→ 段落 B（从 C4 开始）：
不要从 G4 直接跳到 C4（太突兀）
中间可以有一个短过渡：G4 → E4 → C4

段落 A（结束在 C5）→ 段落 B（从 C5 开始）：
保持同一个音，连续感
```

### 段落之间的节奏过渡

```
段落 A（十六分密集）→ 段落 B（四分疏节奏）：
用渐慢或休止过渡：逐渐拉长音符时值
最后一个十六分 → 八分 → 四分 → 半休止 → 开始新段落

段落 A（疏节奏）→ 段落 B（密节奏）：
用 fill（填充乐句）过渡：1–2 小节的音符加密
```

### 段落之间的织体过渡

```
稀疏 → 丰富：
逐步加入新声部（先加入贝司 → 再加入和弦 → 再加入旋律）

丰富 → 稀疏：
逐步去掉声部（先去掉旋律 → 再去掉和弦 → 最后只剩贝司或消失）

不变但变化：
同一织体但换音区（从低区换到高区，感觉完全不同）
```

## 七、完整乐曲的设计流程

当 AI 需要创作一段完整的音乐时，应按以下流程设计：

```
第 1 步：确定风格和情绪
第 2 步：确定 BPM 和拍号
第 3 步：确定调式
第 4 步：设计核心动机（2–4 个音）
第 5 步：设计曲式结构（AABA / ABAB / Intro-Verse-Chorus...）
第 6 步：为每个段落分配音区、节奏密度、织体厚度
第 7 步：设计动态曲线
第 8 步：为每个段落写旋律（使用动机发展手法）
第 9 步：为每个段落配和弦
第 10 步：加入转音、装饰、填充等细节
第 11 步：添加过渡段落（Pre-chorus、fill 等）
第 12 步：设计结尾
第 13 步：整体检查：音域是否合理、节奏是否统一、力度是否有起伏
```

## 八、常见曲式问题与修正

### 问题 1：段落之间没有过渡

```
❌ 主歌结束 → 副歌直接开始，像两个不相干的段落
✅ 加入预副歌（Pre-chorus）作为过渡
```

### 问题 2：所有段落都在同一个音区

```
❌ 主歌 C4–G4，副歌 C4–G4，桥段 C4–G4（没有区分）
✅ 主歌 G3–C4，副歌 C4–G4，桥段 G4–C5（各有特色音区）
```

### 问题 3：副歌不够"副歌"

```
❌ 副歌的音域、节奏、织体与主歌没有区别
✅ 副歌应该是整首歌最"高"的部分：最高音、最密节奏、最丰富织体
```

### 问题 4：结尾太突然

```
❌ 最后一个音之后就没了
✅ 加入 Outro：渐弱、回归 intro 素材、或延长最后一个和弦
```
