# 调式互换、转调与和声色彩进阶

本文件提供高级和声技巧，帮助 AI 在和弦写作中使用调式互换、转调和特殊和弦，创造出更丰富、更有风格的音乐。

---

## 一、调式互换（Modal Interchange / Borrowed Chords）

### 概念

从平行调式借用和弦，为大调增加色彩深度，为小调增加明亮感。

```
C 大调的平行小调是 c 小调
C 大调可以借用 c 小调中的任何和弦

C 大调的平行调式还有：
- C 多利亚（借用 D Dorian 的和弦）
- C 弗里吉亚（借用 E Phrygian 的和弦）
- C 利底亚（借用 F Lydian 的和弦）
- 等等
```

### 最常用的借用和弦

| 和弦 | 标记 | 来源 | 在 C 大调中的效果 |
|------|------|------|-----------------|
| bVII | Bb | c 小调的 VII | 摇滚感、开放感 |
| bVI | Ab | c 小调的 VI | 突然下沉、戏剧性 |
| bIII | Eb | c 小调的 III | 忧郁下沉 |
| iv | Fm | F 小调的 i | 忧郁的替代 IV |
| ii° | Ddim | a 小调的 ii° | 增加张力 |
| bII | Db | 那不勒斯和弦 | 强烈的不稳定性 |

### 调式互换的使用时机

1. **副歌之前**：在预副歌的最后一个和弦使用借用和弦，制造悬念
2. **桥段**：桥段使用借用和弦，制造与主歌/副歌的色彩对比
3. **终止前**：在终止前用 bVII 替代 IV，创造意外的解决感

### 经典调式互换进行

```
Led Zeppelin 式：
I – bVII – IV – I
C – Bb – F – C

迷幻摇滚：
I – vi – bVII – IV
C – Am – Bb – F

蓝调摇滚：
I – bIII – IV – I
C – Eb – F – C

"玛利亚和弦"（流行歌中最感人的和弦之一）：
IV – iv – I
F – Fm – C
（IV 大 → IV 小 → I，从光明瞬间跌入黑暗再回归光明）
```

## 二、转调（Modulation）

### 转调类型

| 类型 | 方法 | 效果 |
|------|------|------|
| 共同和弦转调 | 通过一个两调共有的和弦过渡 | 平滑、自然 |
| 半音转调 | 将和弦整体移高/移低半音 | 突然但有力 |
| 属和弦转调 | 在新调的属七和弦上引入，然后解决到新主和弦 | 最有说服力的转调 |
| 直接转调 | 没有任何准备直接换调 | 突然、戏剧性 |

### 常用转调目标

从 C 大调出发：

```
转高半调到 C#/Db 大调 → 更有张力、更明亮
转高纯四度到 F 大调 → 开放感增加
转高纯五度到 G 大调 → 更明亮、更有力
转低纯五度到 F 大调 → 温暖感（关系大小调转换）
转关系小调到 a 小调 → 突然变暗
```

### 转调的具体操作

#### 共同和弦转调示例：C 大调 → G 大调

```
C 大调的 C 和弦 = G 大调的 IV 和弦
过渡：
| C | Am | D7 | G |  （通过 D7 这个 G 大调的属和弦实现转调）
```

#### 属和弦转调示例：C 大调 → A 大调

```
A 大调的属和弦是 E7（E–G#–B–D）
过渡：
| C | C#dim | Dm | E7 | Am |
（E7 的出现暗示了 Am → 解决到 A 大调的 A）
```

### 转调在曲式中的应用

| 位置 | 转调方向 | 效果 |
|------|---------|------|
| 最后一次副歌 | 转高半音或全音 | 最后的能量爆发 |
| 桥段 | 转关系小调 | 情绪对比 |
| 间奏 | 转属方向 | 推动感 |
| 第二段主歌 | 转低纯五度 | 回到舒适区但有变化 |

## 三、特殊和弦

### 那不勒斯和弦（Neapolitan Chord）

- bII 级大三和弦
- 通常以第一转位（bII/4）出现
- 制造强烈的戏剧性和不稳定性

```
C 大调中的那不勒斯和弦：Db 大三和弦
使用：Db – G7 – C（替代正常的 ii – V – I）
效果：比 ii – V – I 更有冲击力
```

### 增六和弦

- 包含增六度音程（等音程为减七度）
- 倾向于解决到属和弦
- 最常用的是意大利增六、法国增六、德国增六

```
C 大调中的增六和弦示例：
意大利增六：A – C – F#（F# 是增六度音，解决到 G）
使用场景：在终止前替代 V 和弦
```

### 减七和弦

- 由四个小三度堆叠而成
- 对称结构，可以等音移到 4 个不同位置
- 制造极强的紧张感

```
C 减七和弦：C – Eb – Gb – Bbb（A）
可移动到：Cdim7 → Ebdim7 → Gbdim7 → Adim7（同一个和弦，不同音名）
使用：在转调中作为过渡和弦（"共同减七"）
```

### 挂留和弦（Sus Chords）再谈

| 类型 | 写法 | 解决 | 情绪 |
|------|------|------|------|
| sus2 | Csus2 = C–D–G | → C | 空灵、民谣 |
| sus4 | Csus4 = C–F–G | → C | 期待、悬空 |
| 7sus4 | C7sus4 = C–F–G–Bb | → C7 | 蓝调、爵士 |
| 9sus4 | C9sus4 = C–F–G–Bb–D | → C9 | 爵士、R&B |

**sus4 是最有用的挂留和弦**，它在流行歌中无处不在：

```
Gsus4 → G：流行歌中最经典的和弦变化
用在高潮前的最后一个小节，制造"即将爆发"的期待感
```

## 四、和弦色彩进阶选择

### 大三和弦的变体

| 变体 | 写法 | 色彩 |
|------|------|------|
| 大三 | C | 明亮、稳定 |
| 大七 | Cmaj7 | 温暖、梦幻 |
| 大九 | Cmaj9 | 更丰富的梦幻 |
| 大六 | C6 (C–E–G–A) | 民谣、乡村 |
| 大六九 | C6/9 | 阳光、度假感 |

### 小三和弦的变体

| 变体 | 写法 | 色彩 |
|------|------|------|
| 小三 | Am | 忧郁 |
| 小七 | Am7 | 更柔和的忧郁 |
| 小九 | Am9 | 爵士感的忧郁 |
| 小十一 | Am11 | 空灵的忧郁 |
| 小大七 | Am(maj7) | 紧张、戏剧性（罕见）|

### 属和弦的变体

| 变体 | 写法 | 色彩 |
|------|------|------|
| 属七 | G7 | 不完美、需要解决 |
| 属九 | G9 | 爵士感 |
| 属十三 | G13 | 蓝调/爵士 |
| 减七 | Bdim7 | 极紧张 |
| 半减七 | Bm7b5 | 爵士小调 |
| 属七升九 | G7#9 | 摇滚、蓝调（Jimi Hendrix 和弦）|

## 五、色彩和弦速查：什么时候用什么

| 场景 | 推荐和弦 | 避免 |
|------|---------|------|
| 主歌开头 | I 或 vi | 不要一开始就用 V7 |
| 副歌开头 | I 或 IV | 不要用减和弦 |
| 桥段 | bVII、bVI、iv | 不要用原位 I |
| 终止 | V7 – I | 不要用 I – I |
| 半终止 | V7 | 不要用 I |
| 转调 | 共同和弦 → 新调的 V7 | 不要直接跳 |
| 间奏 | ii – V – I | 不要只用 I |
| 结尾 | Imaj7 或 I6 | 不要用 V7（除非刻意开放）|

## 六、给配和弦的具体建议

在配和弦任务中，AI 应该：

1. **先确定调式**（参考 13_调性识别）
2. **选择基础进行**（参考 08_和弦进行词典）
3. **考虑风格**（参考 12_风格化写作）
4. **应用调式互换**：在桥段或预副歌使用 1–2 个借用和弦
5. **加入七和弦**：在 V 和弦上使用 V7，在其他和弦上酌情使用 maj7/m7
6. **使用挂留和弦**：在 I 和 V 上考虑 sus4
7. **检查低音线**：确保低音线流畅
8. **润色**：确保 legato、力度、音域合理

### 配和弦的"调味公式"

```
基础进行（骨架）：
I – IV – V – I

调味后（丰富）：
Imaj7 – IVmaj7 – Vsus4 – V7 – Imaj7

调味后（摇滚）：
I – bVII – IV – I

调味后（爵士）：
Imaj7 – vi7 – ii7 – V7 – Imaj7

调味后（带调式互换）：
I – bVII – IV – iv – I
（注意 iv 是从平行小调借来的）
```
