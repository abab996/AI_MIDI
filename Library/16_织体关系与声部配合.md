# 旋律与伴奏的织体关系

本文件指导 AI 如何让旋律与和弦/伴奏之间形成良好配合，避免"各玩各的"或"互相打架"。

---

## 一、织体基本类型

### 主调织体（Homophonic）

旋律在上方独唱，和弦在下方伴奏。最常见于流行、民谣。

```
旋律：G4 – A4 – B4 – C5（上方独立声部）
伴奏：C – C – G – G（下方和弦节奏型）
关系：旋律主导，伴奏服务于旋律
```

### 复调织体（Polyphonic）

多个声部地位平等，各自有独立的旋律线。如赋格、卡农。

```
声部 1：C4 – E4 – G4 – C5
声部 2：E3 – G3 – C4 – E4（卡农，延迟 1 小节）
声部 3：G2 – C3 – E3 – G3（再延迟 1 小节）
关系：三条线都是旋律，互相交织
```

### 支声织体（Heterophonic）

一个主旋律 + 一个变形的平行声部。常见于民族音乐。

```
主旋律：C4 – D4 – E4 – G4
支声声部：C4 – D4 – E4 – G4（节奏微变，加花）
关系：基本相同但有装饰差异
```

## 二、旋律与伴奏的配合策略

### 策略 1：间隙填充（Gaps）

伴奏只在旋律的间隙中发声，旋律是主角。

```
旋律：C4 _ E4 _ G4 _ _ _ （有休止）
伴奏：C-E-G _ _ C-E-G _ _ （填补旋律的间隙）

原则：伴奏永远不能盖过旋律
实现：伴奏音符的 start 避开旋律音符的 start
```

### 策略 2：节奏互补

旋律和伴奏的节奏型互相错开，形成织体厚度。

```
旋律：X _ X _ X _ X _ （四分音符）
伴奏：_ X _ X _ X _ X （反拍八分音符）
效果：上下交错，形成完整的节奏织体
```

### 策略 3：低音与旋律的对话

贝斯线不是单纯的和弦根音，它可以是一条独立的旋律。

```
旋律（中高区）：C5 – B4 – A4 – G4 – F4 – E4 – D4 – C4
贝斯（低区）：C2 – _ – G2 – _ – A2 – _ – E2 – _ （只弹根音）
更好：C2 – B1 – A1 – G1 – F1 – E1 – D1 – C1 （级进下行，也是旋律）
```

### 策略 4：呼应式（Call and Response）

旋律提出一个"问题"，伴奏"回答"。

```
旋律（Call）：G4 – A4 – B4 – C5（上行，开放感）
伴奏（Response）：E4 – D4 – C4 – G3（下行，解决感）

或者：
旋律（Call）：C4 – E4 – G4（大三和弦分解上行）
贝斯（Response）：C2 – G2 – C2（根音确认）
```

## 三、音区分配规则

### 多声部的音区间距

```
高音区（旋律）：C4–C6
中高区（和声上方）：C3–C5
中音区（和声中间）：C2–C4
中低区（和声下方/贝斯）：C1–C3

原则：
- 相邻声部之间至少隔一个八度（或至少三度）
- 绝不交叉：上声部不低于下声部
- 绝不超越：声部 A 不要跳到声部 B 的音区
```

### 钢琴织体的标准分配

```
右手（高音声部）：旋律 + 高音装饰 = C4–C6
左手（低音声部）：和弦根音/五度 + 低音行进 = C1–C4
中间留出空间（C3–C4 之间可以有空隙，或让左手偶尔进入 C3）

错误示例：
右手：C4–G4
左手：E4–G4（与右手重叠，浑浊）
```

### 吉他织体的分配

```
吉他 6 根弦的音域：E2–E4（标准调弦）
旋律线：G3–E4（在中高把位）
和弦伴奏：C2–G3（开放和弦 + 低音）
节奏型：分解和弦，低音 + 中音交替
```

### 弦乐织体的分配

```
第一小提琴：旋律 = G4–E5
第二小提琴：和声填充 = D4–B4
中提琴：和声内声部 = G3–D4
大提琴：低音 + 偶尔旋律 = C2–G3
倍大提琴：持续低音 = E1–C3
```

## 四、和弦与旋律的冲突避免

### 冲突 1：和弦音与旋律音打架

```
旋律音：C5
和弦：Am (A–C–E)
和弦中的 C 音与旋律的 C5 形成八度 → ✅ 共同音，没问题

旋律音：F5
和弦：Am (A–C–E)
旋律 F 不在 Am 和弦内 → 如果是经过音/弱拍 → ✅ 可接受
                       → 如果是强拍 → ⚠️ 考虑换和弦
```

### 冲突 2：和弦变化时旋律音变成非和弦音

```
旋律持续音：C4（从第 1 拍到第 3 拍）
和弦变化：第 2 拍从 Am 变成 F
第 2 拍旋律 C 不在 F 和弦内 → 变成非和弦音

处理方式：
- 如果旋律 C 在强拍 → 不要在那个位置换和弦
- 如果旋律 C 在弱拍 → 可以换和弦，C 作为经过音
- 或者选择 Dm 代替 F（Dm 包含 C）
```

### 冲突 3：低音与旋律形成不想要的音程

```
旋律：C5
贝斯：G2
C5 – G2 = 纯十二度 → ✅ 协和，没问题

旋律：C5
贝斯：F#2
C5 – F#2 = 增十二度（等于增一度）→ ❌ 极不协和
（除非刻意制造不协和效果）
```

## 五、伴奏织体模板

### 模板 A：分解和弦（Arpeggio）

```
适合：钢琴、吉他、竖琴
结构：把和弦音一个一个弹出来
模式：
| C3 – E3 – G3 – C4 – G3 – E3 |  （上行再下行）
| C3 – G3 – E3 – C4 – G3 – E3 |  （低–高–中循环）
| C3 – E3 – G3 – C4 – E3 – G3 |  （低音先行，高音延续）
```

### 模板 B：柱式和弦（Block Chord）

```
适合：钢琴强奏、摇滚吉他
结构：和弦音同时发声
模式：
| [C3,E3,G3] – [C3,E3,G3] – [G2,B2,D3] – [G2,B2,D3] |
（每拍或每半拍一次）
```

### 模板 C：节奏吉他型

```
适合：流行、摇滚
结构：强力和弦 + 闷音
模式：
| C5(强) – C5(闷) – C5(闷) – C5(闷) – G5(强) – G5(闷) – G5(闷) – G5(闷) |
```

### 模板 D：Walking Bass

```
适合：爵士
结构：每拍一个音，级进为主
模式：
| C2 – D2 – E2 – F2 |  （4 拍，每拍一个音级进）
| C2 – _ – A1 – G1 |  （第 2 拍休止）
```

### 模板 E：Pad / 铺底

```
适合：电子、氛围
结构：长音和弦，缓慢变化
模式：
| [C3,E3,G3] start=0 end=4 |  （持续 4 拍）
| [F3,A3,C4] start=4 end=8 |  （4 拍后换和弦）
特点：音符时值长，创造氛围感
```

## 六、织体层次设计

### 三层织体（最常用）

```
高音层（旋律）：独立的旋律线，最突出
中音层（和声）：和弦分解或节奏型，支撑
低音层（低音）：根音行进，根基
```

### 四层织体（丰富编曲）

```
高音层（旋律）：主旋律
次高音层（和声上方）：和弦音分解，增加厚度
中音层（节奏型）：八分或十六分节奏，制造律动
低音层（贝斯）：根音或独立低音线
```

### 层次之间的互动规则

| 规则 | 说明 |
|------|------|
| 避免同时满 | 总有一个层次在"休息" |
| 层次进出 | 各层在不同段落出现/消失 |
| 动态对比 | 某层突然消失会产生"空"的感觉 |
| 旋律优先 | 旋律出现时，其他层降低存在感 |

---

## 七、输出织体时的注意事项

当 AI 需要输出包含旋律 + 和弦/伴奏的 note_table 时：

1. **明确区分角色**：旋律音符 velocity 高，伴奏音符 velocity 低
2. **时间不重叠**：伴奏的 start 时间避开旋律的强拍（除非刻意制造对位）
3. **音区分开**：旋律在中高区，伴奏在中低区，避免音区重叠
4. **节奏互补**：旋律和伴奏使用不同的节奏型，不要完全同步
5. **织体变化**：不同段落使用不同的织体（intro 稀疏，chorus 丰富）
