# 节奏与律动

本文件为 AI 提供节奏写作的专业知识，帮助创作出有律动感、有生命力的节奏型。

---

## 一、节奏基础

### 拍（Beat）

- 音乐的基本时间单位
- BPM（每分钟节拍数）定义了一拍有多快
- 4/4 拍中，数字 "4" 表示每小节有 4 拍

### 强拍与弱拍

| 拍位 | 4/4 拍中的位置 | 强弱 |
|------|--------------|------|
| 正拍（Downbeat） | 第 1 拍 | 最强 |
| 次强拍 | 第 3 拍 | 次强 |
| 弱拍（Backbeat） | 第 2、4 拍 | 弱 |
| 弱位（Off-beat） | 两拍之间 | 最弱 |

### 时值对应表（以 4/4 拍、BPM 120 为例）

| 音符 | 拍数 | 毫秒（BPM 120） |
|------|------|----------------|
| 全音符 | 4 | 2000 |
| 二分音符 | 2 | 1000 |
| 四分音符 | 1 | 500 |
| 八分音符 | 0.5 | 250 |
| 十六分音符 | 0.25 | 125 |
| 三十二分音符 | 0.125 | 62.5 |
| 附点四分 | 1.5 | 750 |
| 附点八分 | 0.75 | 375 |

## 二、常见节奏型

### 柱式和弦型（适合吉他/钢琴伴奏）

```
| 1 & 2 & 3 & 4 & |
| X   X   X   X   |  （四分音符柱式）
| X X X X X X X X |  （八分音符柱式）
| X   X     X   |  （切分柱式）
```

### 分解和弦型（Arpeggio）

```
| 1 & 2 & 3 & 4 & |
| 1 2 3 1 2 3 1 2 |  （六八分解：低–中–高 循环）
| 1 2 3 4 3 2 1 2 |  （波浪分解）
| 1   3   5   |  （琶音：每拍一个音，跳进）
```

### 八分音符律动型

```
| 1 & 2 & 3 & 4 & |
| X   X X   X   X X |  （Funk 基本型：反拍重音）
| X X   X   X X   X |  （Reggaeton 型）
```

### 十六分音符花型

```
| 1 e & a 2 e & a 3 e & a 4 e & a |
| X   X   X   X   X   X   X   |  （每三个十六分一个音）
| X X X X X X X X X X X X |  （连续十六分，能量感）
|     X   X     X   X     |  （反拍十六分，切分感）
```

### 休止节奏型

```
| 1 . 2 . 3 . 4 . |  （每拍后半拍一个音）
| 1 & . & 3 & . & |  （强弱交替中的休止，摇摆感）
| X . . X . . X . |  （稀疏有力的节奏）
```

## 三、切分（Syncopation）

切分是把重音从正拍移到弱位上的技巧，是创造律动感的关键。

### 切分原理

- 正常：重音在正拍（1、2、3、4）
- 切分：重音移到弱位（&、e、a）

### 常见切分模式

```
模式 A（反拍切分）：
| 1 & 2 & 3 & 4 & |
| . X . X . X . X |  （每个 & 上有音）

模式 B（后半拍切分）：
| 1 . 2 . 3 . 4 . |
| . . X . . . X . |  （每拍后半拍有音）

模式 C（三连音切分）：
| 1 & a 2 & a 3 & a 4 & a |
| . . X . . X . . X . . X |  （三连音中的第 3 个）

模式 D（切分附点）：
| 1 . 2 . 3 . 4 . |
| X . . X . X . . |  （附点音符结尾，下一音延迟）
```

### 切分的情绪效果

| 切分类型 | 情绪 | 风格 |
|---------|------|------|
| 轻切分 | 摇摆、轻松 | 爵士、流行 |
| 重切分 | 紧迫、推动 | 摇滚、电子 |
| 持续切分 | 律动感 | Funk、R&B |
| 突然切分 | 惊讶、转折 | 戏剧性 |
| 三连音切分 | 流动、加速 | Hip-hop、现代 R&B |

## 四、Groove 设计

### 什么是 Groove

Groove 是节奏中"让人想跟着动"的部分，由以下几个要素组成：

1. **律动模式**：节奏型的整体骨架
2. **微调**：音符不在绝对精确的网格上，略微提前或延后
3. **力度变化**：不是所有音都一样响
4. **摇摆感**：八分音符不平均分配

### 各风格的 Groove 特征

#### 流行/摇滚

```
特征：反拍重音（2、4 拍），四分和八分音符为主
鼓点：底鼓在 1、3；军鼓在 2、4
速度感：直接、有力
```

#### Funk

```
特征：十六分音符花式律动，切分密集
鼓点：底鼓 + 军鼓 + 踩镲复杂交织
速度感：紧凑但有余韵，想让人抖脚
```

#### Hip-hop

```
特征：大拍上的重音 + 弱位上的流动
鼓点：底鼓偏重 + 踩镲密集
速度感：慵懒但有力，head-nodding
```

#### Jazz（摇摆）

```
特征：八分音符不均匀（三连音感觉），后半拍更重
鼓点：踩镲在 1 和 3，军鼓在 2 和 4，底鼓灵活
速度感：律动流畅，想让人摇摆
```

#### Reggaeton

```
特征：底鼓在每拍，但第 3 拍和最后一拍特别重
鼓点：Dem Bow 节奏型
速度感：舞蹈感极强
```

#### EDM/House

```
特征：四四拍，底鼓在每拍
鼓点：四四拍底鼓 + 开镲在反拍
速度感：持续前进，让人想跳舞
```

## 五、节奏写作技巧

### 技巧 1：节奏对比

在一段音乐中交替使用密节奏和疏节奏：

```
密节奏段：十六分音符跑动 → 制造能量、紧张
疏节奏段：长音 + 休止 → 释放、呼吸
```

### 技巧 2：节奏型重复与微变

- 先确定一个基础节奏型
- 重复 2 次
- 第三次微变（加一个花、少一个音）
- 第四次回归原版
- 这创造了"期待–惊喜–满足"的感觉

### 技巧 3：切分渐进

```
第一遍：全部在正拍（稳定）
第二遍：加入少量切分（开始律动）
第三遍：更多切分（律动加强）
第四遍：回归正拍（释放）
```

### 技巧 4：休止的妙用

- 长音之后的休止 = 惊讶
- 密集音符之后的休止 = 呼吸、期待
- 乐句开头前的休止 = 蓄势待发
- 切分休止 = 让听众"摔倒"然后接住

### 技巧 5：三连音的魔力

三连音（三个音占两拍的时间）能创造独特的流动感：

```
用在节奏型的任何位置都可以：
三连音过渡 → 制造加速感
三连音收尾 → 制造收束感
三连音替代二分音符 → 填充空档
```

## 六、旋律节奏模板

### 模板 A：说话式（最自然的旋律节奏）

```
特点：长短不一，像说话的抑扬顿挫
参考：
| X   X X   X     X X X |  （长短交替）
| X   X   X   X   X   |  （每拍一个音，像朗诵）
```

### 模板 B：舞蹈式

```
特点：规律的节奏型，有重复感
参考：
| X X X X X X X X |  （八分音符持续律动）
| X   X   X   X   |  （切分舞蹈感）
```

### 模板 C：炫技式

```
特点：密集的音符群 + 突然的长音/休止
参考：
| XXXXXXXXX X     |  （一长串 → 突然停）
| X   XXXXXXX X   |  （疏 → 密 → 疏）
```

### 模板 D：抒情式

```
特点：长音为主，少量短音装饰
参考：
| X       X   X       |  （长音 + 短装饰音）
| X     X     X     X |  （每拍一个长音，悠长）
```

## 七、BPM 与节奏密度

| BPM 范围 | 节奏密度建议 | 风格示例 |
|---------|------------|---------|
| < 60 | 极疏，大量长音和休止 | 抒情慢歌、古典慢板 |
| 60–80 | 偏疏，四分音符为主 | 民谣、抒情流行 |
| 80–100 | 适中，八分音符律动 | 流行、轻摇滚 |
| 100–130 | 较密，八分+十六分 | 摇滚、舞曲 |
| 130–160 | 密集，十六分音符常见 | EDM、Techno |
| 160–200 | 极密，密集鼓点 | Drum & Bass、Hardcore |

**注意**：BPM 高时反而应该少用音符（让每个音更重），BPM 低时可以多用音符（增加细节）。

## 八、在 note_table 中写节奏

在 note_table 中，节奏由 `start` 和 `end` 的时间差决定：

| 节奏 | start → end 差值（BPM 120, 4/4 拍） |
|------|-----------------------------------|
| 四分音符 | 0.5 |
| 八分音符 | 0.25 |
| 十六分音符 | 0.125 |
| 附点四分 | 0.75 |
| 三连音之一（占 1/3 拍） | ≈0.167 |

### 节奏精度规则

1. 所有 start 时间从 0 或整数拍开始（如 0, 1, 2, 3...）
2. 十六分音符对齐到 0.125 网格
3. 八分音符对齐到 0.25 网格
4. 可以稍微浮动（如 1.03 而不是严格的 1.0）增加自然感，但不要太大
5. 休止表现为该时间段内没有音符条目
