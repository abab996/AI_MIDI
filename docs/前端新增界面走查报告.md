## 2. 双主题与动效

- **双主题**：所有新增界面只用令牌（`--color-primary/--color-accent/--color-hud/--color-ink*/--color-bg*/--color-border*/--color-danger/--color-grid/--color-shadow`），
  由 `document.documentElement.dataset.theme` 驱动；检查脚本对新增 CSS 段做"无硬编码 hex"断言。
  截图集（每个界面暗蓝 + 暖纸两张）：

  | 界面 | 暗蓝 | 暖纸 |
  |---|---|---|
  | 乐器箱 | `rack-dark.png` | `rack-warm.png` |
  | 音源选择器 | `picker-dark.png` | `picker-warm.png` |
  | 素材库 | `material-dark.png`（含音源页签） | `material-warm.png` |
  | 混音台 | `mixer-dark.png` | `mixer-warm.png` |
  | MM 插件承载窗 | `mm-ui-dark.png` | `mm-ui-warm.png` |

- **动效**：只用 `transform` / `opacity`（脚本断言新增 CSS 段无 `transition: … height`）。
  曲线按规范：条目进场 Stagger 30ms（`--mat-delay`/`--rk-delay`）、面板/条目 `cubic-bezier(0.34,1.56,0.64,1)`（Natural Spring）、
  页签切换 `mat-in` 0.22s、混音台面板 0.3s 上滑。
- **reduced-motion**：`prefers-reduced-motion: reduce` 下逐项关闭（素材库条目/页签切换、混音台面板与推子过渡、
  AI 回显脉冲、MM 承载页骨架脉冲与按钮过渡）——浏览器脚本用 `Emulation.setEmulatedMedia` 实测 `animation-name: none`。

## 5. 本轮修掉的前端/链路缺陷（均有复现证据）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | F9 打开混音台"面板开了但空白" | 键盘监听挂在 `document`，handler 里 `this` 是 document 而非控制器 | 传 `self` |
| 2 | 通道条色条与轨道名消失 | 纵向 flex 高度不足，子项被 `flex-shrink` 压成 0 高 | `.mxr-strip > * { flex: 0 0 auto }` + 收窄推子区 |
| 3 | 素材库采样包标签张冠李戴 | 断言取的是"全局第一个"标签而非目标根目录那一行 | 断言按 `title` 定位目标行 |
| 4 | 效果器被装成乐器 | HTTP `/load` 从 **query** 读 `slot`，POST 的 slot 在 **body** | `slot` 改 `*int`，按 body 解析（load/unload/param/editor 四处统一） |
| 5 | 插件乐器电平恒为 0（两轮误判为"未授权"） | ① `noteOnTrack` 根本不是 IPC 方法（音符发进虚空）② VST3 处理路径崩引擎 | 改用真实 MIDI 帧；不再在实例化后重配 VST3 总线，按插件声明取缓冲 |
| 6 | MM 参数界面无法显示当前值 | MM ABI 有意不提供"读当前值"（权威在宿主），宿主没记账 | 宿主 `values_[]` 记账 + `params` 输出 `value` |
| 7 | MM 乐器被当效果器装入槽 | Go 侧无条件带 `slot=-1`，引擎按 presence 分流 | 统一"按值判断"（`slot<0` = 乐器） |
